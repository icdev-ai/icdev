{# Academy light/dark theme tokens. The Academy was drawn for the dark theme only: cards, sidebars, output panels and hero banners hard-coded near-black backgrounds (#12192b, #0d1221, #060910, #0a0a14 ...) while body text followed the dashboard theme. With the sun toggle (base.html sets html[data-theme="light"]) the text went dark on a still-dark card and lesson content was unreadable. Every such literal in forge_academy/ is now var(--fa-bg-) or var(--fa-tx-). The DARK value of each token IS the original literal, so the dark theme renders exactly as before; the light block gives each a readable counterpart (backgrounds -> light surfaces, text -> darkened until it holds >= 4.5:1 on the lightest surface). The shared accents (--fa-orange, --fa-cyan, --fa-green, --fa-gold ...) are declared on :root by each page; the light block below out-ranks them (html[data-theme] is more specific than :root) with darker values that read as text on white. Included once from _chrome_clearance.html, which every academy page already includes. The SVG skill map keeps its own dark canvas in both themes. #}
