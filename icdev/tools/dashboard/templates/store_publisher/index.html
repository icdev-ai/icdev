Store publisher

Prepares signed {{ schema }} packages (ICDEV[OS] contract {{ contract }}) — an agent, a crew, a skill, an MCP server or a plugin — for ICDEV[OS]'s private, curated agent store. Each carries its publisher identity ({{ view.publisher.id or 'unknown' }}), an A2A Agent Card signed with JWS (ES384) that binds the package's content digest, its SBOM and a dependency report over exactly that SBOM, its declared tools, marking and egress ceilings and budget, the publisher's red-team report, and ICDEV's seven marketplace scanner gates run on it: the publisher's own report, which ICDEV[OS] re-runs and only shows. A gate that could not run says unverified, never passed. The card is signed by the publisher's key from the OS keyring — never a person's, and never at an agent's request. Key: {% if view.signing.configured %}configured{% else %}none configured: a package is refused until the site sets one{% endif %}. A person prepares a package; another person of its organisation publishes it ({{ template }}); a third person imports it into ICDEV[OS], where a reviewer who is none of them certifies it. Nothing here publishes by itself.
