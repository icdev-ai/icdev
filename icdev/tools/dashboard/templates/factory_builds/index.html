Signed factory builds

For each target the factory builds one signed {{ schema }} (ICDEV[OS] contract {{ contract }}): a CycloneDX 1.7 SBOM (an AI-BOM for a model, linked to its fine-tuning registry promotion), SLSA v1.2 provenance, an OpenVEX statement for each vulnerability the factory scan found, Sigstore bundles over the artefact's digest, a model's weights signed with OpenSSF model-signing, and the bundles as OCI referrers. The factory's own key signs (KMS or the OS keyring; keyless only with a configured OIDC issuer) — never a person's key, and never an agent's request. Signing: {{ view.signing.mode or 'unknown' }}{% if not view.signing.configured %}, no key configured: a build is refused until the site sets one{% endif %}. Transparency log: {{ view.transparency_log.mode or 'unknown' }}{% if view.transparency_log.mode == 'off' %} (the default: nothing is sent to a log, and every build records that){% endif %}. A person prepares a build; another person of the target's organisation publishes it to ICDEV[OS]'s release register ({{ template }}). A build is evidence for ICDEV[OS]'s admission, never an approval.
