# IDC IaC Twin (Phase IDC-1)

> Shard of `tools/manifest.md`. See index at `tools/manifest.md`.
>
> Infrastructure Design Canvas IaC Twin — snapshot importer, IQE query surface, pre-apply compliance gate, snapshot writer, and 6h Genesis reflex. Phase 1-4 implementation per `docs/briefs/digital-twin-market-canvas-implementation-plan.md` (IDC §7).

## IDC IaC Twin Core
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| IDC Snapshot Writer | tools/infra_canvas/twin/snapshot_writer.py | [Phase 1] Freeze IDC graph state into `infra_snapshots` at importer-run end. Canonical grain: resource × CSP × region × config × classification × tags → snapshot row. Append-only; never updates existing rows. Redacts known secret fields before insert. | (library) `write_snapshot(project_id, resources: list[dict], classification='CUI')` | `{snapshot_id, project_id, csp_counts, resource_count, taken_at}` |
| IDC Terraform Importer | tools/infra_canvas/twin/importers/terraform.py | [Phase 1] Parses `terraform show -json` output, maps `.values.root_module.resources[*]` to IDC canonical resource types, and calls snapshot writer. Unmapped types stored with `unknown-` prefix. | `--plan-json <file\|->`, `--project-id`, `--classification`, `--json` | `{snapshot_id, imported, skipped, unmapped}` |
| IDC Pulumi Importer | tools/infra_canvas/twin/importers/pulumi.py | [Phase 2] Parses `pulumi stack export --json` checkpoint, maps `.deployment.resources[*]` to IDC canonical types. | `--stack-json <file\|->`, `--project-id`, `--classification`, `--json` | `{snapshot_id, imported, skipped, unmapped}` |
| IDC AWS Importer | tools/infra_canvas/twin/importers/aws_tags.py | [Phase 2] Calls `aws resourcegroupstaggingapi get-resources` (via boto3 or JSON piped in), maps to IDC canonical types, writes snapshot. | `--resources-json <file\|->`, `--project-id`, `--region`, `--json` | `{snapshot_id, imported, skipped}` |
| IDC IQE Adapter | tools/iqe/adapters/infra.py | [Phase 1] Registers IQE collections against `infra_snapshots`: `infra.resources` (full table), `infra.snapshots` (distinct snapshot batches), `infra.latest` (most recent snapshot per project). DSL: `foreach resource in infra where resource_type == 'aws-ec2' and classification == 'CUI' select resource.resource_id, resource.region`. | `import tools.iqe.adapters.infra` | Collections registered on module-level `Executor`; returns result set dicts |
| IDC Pre-Apply Gate | tools/infra_canvas/preapply_gate.py | [Phase 1] Parses `terraform plan -json`, computes resource delta (add/modify/delete), runs all `infra/*` IQE seed checks against planned final state. Exits 1 on fail when `--gate` set. | `--gate`, `<plan.json\|->`, `--project-id`, `--classification`, `--json` | `{gate: pass\|fail, violations: [...], delta: {add, modify, delete}}` |
| IDC Compliance Gate | tools/infra_canvas/twin/compliance_gate.py | [Phase 3] Evaluates a delta snapshot (proposed change) against FIPS 199/200, FedRAMP baseline, STIG checks, and IL boundary rules. Flags resources crossing IL boundaries or missing required FIPS controls. | `run_gate(snapshot_id, delta_snapshot_id, project_id)` | `{gate: pass\|fail, fips_violations, fedramp_violations, il_boundary_crossings, stig_findings}` |
| IDC Twin Reflex | tools/infra_canvas/twin/reflex.py | [Phase 2] Genesis 6h reflex — calls Terraform/AWS importers for all registered projects, writes new snapshot batch, diffs vs previous snapshot for drift detection (resources added/removed/changed), and emits drift events to `idc_drift_events`. | Genesis reflex config dict | `{projects_processed, resources_snapshotted, drift_events_emitted}` |
| IDC Cross-CSP Twin | tools/infra_canvas/twin/cross_csp.py | [Phase 4] Simulates migrating a workload from one CSP to another. Joins two snapshots on `resource_type` (via CSP equivalence map), surfaces cost delta, compliance delta (FedRAMP IL changes), and performance deltas. | `simulate_migration(src_snapshot_id, tgt_csp, project_id)` | `{resources_mapped, cost_delta, compliance_delta, il_boundary_changes, unmapped_types}` |
| IDC Twin Dashboard API | tools/dashboard/api/idc_twin.py | [Phase 2] Flask Blueprint: `GET /infra/twin/projects` (snapshot posture per project), `GET /infra/twin/project/<id>` (drill-down: latest snapshot, drift events, compliance status), `POST /infra/twin/simulate` (what-if: pre-apply gate over a proposed plan). | Blueprint routes | JSON: `{project_id, snapshot_id, resource_count, drift_events, gate_status, classification_breakdown}` |

## IDC IaC Twin DB Tables
| Table | Purpose |
|-------|---------|
| `infra_snapshots` | Core IDC twin primitive. Append-only. Columns: `snapshot_id` (UUID, part of PK), `project_id`, `csp` (CHECK: 10 CSP values), `region`, `resource_type`, `resource_id` (part of PK), `config_json` (redacted), `classification` (CHECK: 4 levels), `tags_json`, `taken_at`. Indexed on `(snapshot_id, csp)` and `(project_id, taken_at)`. Schema: `docs/features/phase-idc-twin-schema.md`. |
| `idc_iqe_rules` | Seed IQE rule set (10 infra checks). Columns: `rule_id`, `csp`, `dsl_text`, `severity` (critical/high/medium/low), `enabled`. |
| `idc_drift_events` | Drift log from reflex. Columns: `drift_id`, `project_id`, `snapshot_id_old`, `snapshot_id_new`, `resource_id`, `drift_type` (added/removed/changed), `detected_at`. |
| `idc_gate_runs` | Gate run audit trail. Append-only. Columns: `gate_run_id`, `project_id`, `snapshot_id`, `plan_hash`, `verdict` (pass/fail), `violation_count`, `run_at`. |
