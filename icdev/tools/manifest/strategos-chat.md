# Strategos Chat

> Shard of `tools/manifest.md`. See index at `tools/manifest.md`.

## Strategos Chat

| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| STRATEGOS_SYSTEM_PROMPT | tools/strategos/strategos_chat.py | Module-level constant. Military intelligence analysis system prompt defining BLUF format, source priorities (sg_conflict_events → sg_orbat_units → sg_intelligence_briefs → sg_corpus_documents), behavior guidelines (classified markings, analytic confidence caveats, I&W triggers), and entity context handling for the Strategos analyst persona. | Imported by create_strategos_context() | str — LLM system prompt injected into ChatManager session |
| StrategosRAG | tools/strategos/strategos_chat.py | RAG retriever that queries four sg_* tables in priority order: _query_conflict_events() (keyword + recency), _query_orbat_units() (unit name / designation match), _query_briefs() (last 30 days of sg_intelligence_briefs), _query_corpus() (sg_corpus_documents doctrine). Returns top-k deduplicated chunks. Entry point: retrieve(query, top_k=5). Falls back gracefully when tables are empty. | retrieve(query: str, top_k: int = 5) — requires get_connection() from tools.db.storage | list[dict] — each dict: {source, content, relevance_score, metadata} |
| create_strategos_context | tools/strategos/strategos_chat.py | Factory function. Creates or resumes a ChatManager context pre-seeded with STRATEGOS_SYSTEM_PROMPT. Returns (context_id, ChatManager) ready for send/receive. Called by the /api/strategos/chat/init route on panel open. | create_strategos_context(context_id: str \| None = None) — optional existing context_id for resume | (context_id: str, manager: ChatManager) |
| inject_entity_context | tools/strategos/strategos_chat.py | Injects a structured entity summary into an active chat session as a synthetic user turn. Supports seven entity types: vessel, ghost_vessel, kg_node, orbat_unit, supply_node, signal, intel_brief. Renders one of seven pre-formatted templates with entity fields, then calls manager.send(). Used by /api/strategos/chat/{context_id}/inject. | inject_entity_context(context_id: str, entity_type: str, entity_data: dict) — entity_type must match a known template key | ChatManager response dict for the injected turn |
| strategos-chat.js | tools/dashboard/static/js/strategos-chat.js | Client-side IIFE for the Strategos floating chat panel. Manages panel lifecycle (openPanel / closePanel / toggleMinimize), initialises a chat context via POST /api/strategos/chat/init, sends messages via POST /api/strategos/chat/{context_id}/send, and injects entity context via POST /api/strategos/chat/{context_id}/inject. Polls /api/strategos/chat/poll/{context_id} every 2 s to append new assistant messages. Exposes window.openStratChat(entityType?, entityData?) and window.sgChat = {open, close, showMenu, hideMenu} for use by other dashboard pages. Right-click context menu triggers entity injection from any dashboard element that sets data-sg-entity-type / data-sg-entity-id. | Loaded via <script> in _chat_panel.html; depends on marked.js for markdown rendering | DOM mutations to #sg-chat-panel, #sg-chat-messages; public JS API on window.sgChat |
| _chat_panel.html | tools/dashboard/templates/strategos/_chat_panel.html | Jinja2 partial template. Renders the complete Strategos floating chat UI: FAB trigger button (#sg-chat-fab), sliding panel (#sg-chat-panel, 420×540 px), header bar with live-dot indicator and minimize/close controls, entity badge display, scrollable message stream (#sg-chat-messages, max 2000 px), animated typing indicator, textarea + send button, and right-click context menu. Dark-theme with CSS custom properties (--sgc-void, --sgc-amber, --sgc-green, --sgc-cyan). Includes welcome empty-state with satellite icon. Included via {% include %} in any Strategos page that needs the chat panel; requires strategos-chat.js to be loaded after. | {% include 'strategos/_chat_panel.html' %} — no template variables required | Rendered HTML + inline CSS + <script src> reference for strategos-chat.js |
