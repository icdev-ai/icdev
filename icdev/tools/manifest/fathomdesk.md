## FathomDesk

| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Blueprint | tools/fathomdesk/blueprint.py | Flask blueprint for FathomDesk API: GET /api/bars (OHLCV bars via DataGateway, OpenBB→yfinance fallback) and GET /fathomdesk/api/traps (trap event history with ticker/type filters, max 200 rows). Registered via _mount_inline in tools/dashboard/api/__init__.py. | (library — registered in app factory) | JSON responses |
| OpenBB Gateway | tools/fathomdesk/openbb_gateway.py | OpenBB SDK wrapper; graceful fallback if not installed; 5 methods: price, fundamentals, options_chain, news, macro_indicator | --ticker SYM --method get_price --json | Method result or fallback response |
| Signal Generator | tools/fathomdesk/signal_generator.py | Threshold-gated signal filtering — loads `args/signal_thresholds.yaml` and filters candidate signals by min_confidence (default 0.60) and min_score (default 0.50); caps output at max_signals (default 20). Falls back to hardcoded defaults on missing/unreadable YAML. Entry point: `generate(signals, thresholds=None)`. No LLM — fully deterministic. | N/A (library; `from tools.fathomdesk.signal_generator import generate`) | Filtered list of signal dicts |
| Signal Tuner | tools/fathomdesk/signal_tuner.py | Signal tuning utility — threshold optimisation with dry-run support. `dry_run(signals)` previews the full tuning pipeline (load_thresholds → filter_signals → score_backtest → emit_report) without writing to the database. Returns step descriptors, current threshold values, and input signal count. No LLM — fully deterministic. | N/A (library; `from tools.fathomdesk.signal_tuner import dry_run`) | Dict with dry_run flag, steps list, thresholds, and input_signals count |
| FF3 Factor Model | tools/fathomdesk/factor_model.py | Fama-French 3-factor exposure model. Downloads daily FF3 factors from Kenneth French's data library (HTTPS, 24h cache in system temp), fetches ticker OHLCV via DataGateway, aligns on common dates, and fits OLS regression of excess returns on Rm-Rf, SMB, HML using `numpy.linalg.lstsq`. Requires ≥ 30 aligned observations (default lookback 252 days). Entry point: `compute_factor_exposure(ticker, as_of_date?, lookback?)`. CLI: `python tools/fathomdesk/factor_model.py AAPL`. | `compute_factor_exposure(ticker, as_of_date?, lookback?)` | `{beta_market, beta_smb, beta_hml, r_squared, as_of_date}` |
| Data Gateway (with NAV + intl routing + DeFi) | tools/fathomdesk/data_gateway.py | `fundamentals_with_nav(ticker)` — augments base fundamentals with explicit `nav_per_share` (yfinance `navPerShare`/`bookValue`) for Tier 1 sectors (REITs, banks, insurers) and injects `sector_tier` (1/2/3) for all tickers. Phase B: `_is_intl_ticker(symbol)` helper detects exchange-qualified tickers (e.g. CNC.TO, 7203.T, 0700.HK) and routes historical bars directly to yfinance, skipping OpenBB (Alpaca covers US equities only). Phase E: `fetch_defi_yield(protocol)` — fetches TVL and APY for DeFi protocols (Aave, Compound, Uniswap, Jupiter) via DefiLlama yields API and Coingecko token price; graceful degradation on network failure. Returns `{protocol, tvl_usd, apy_mean, pool_count, token_price_usd, source}`. Falls back gracefully when yfinance unavailable. | N/A (library; `FathomDeskDataGateway().fundamentals_with_nav(ticker)`, `FathomDeskDataGateway().fetch_defi_yield(protocol)`) | Fundamentals dict + nav_per_share + sector_tier / DeFi yield dict |
| LLM Factory | tools/fathomdesk/llm_factory.py | Per-agent LLM provider override factory — wraps `LLMRouter` so each FathomDesk analyst agent can declare a preferred provider without touching router internals. Resolution: (1) `agent_llm_overrides[agent_name]` from `args/fathomdesk_config.yaml` → router function key, (2) agent name as fallback function key. Config maps: fundamentals_agent/macro_agent → Sonnet, technical_agent/sentiment_agent → ollama/llama3, debate_engine/risk_manager → Opus. Singleton router; cache is module-level. | N/A (library; `from tools.fathomdesk.llm_factory import get_llm; llm = get_llm("news_analyst")`) | Callable `(LLMRequest) → LLMResponse` |
| Ticker Universe Config | args/fathomdesk_universe.yaml | Canonical source for all tickers tracked by the FathomDesk KG and scanner. Phase B adds `international_tickers` with three markets: TSX/CAD (CNC.TO, SU.TO, RY.TO), Tokyo/JPY (7203.T, 6758.T, 9984.T), Hong Kong/HKD (0700.HK, 9988.HK, 0005.HK). Phase E adds `defi_protocols` section: 4 protocols (aave-v3/lending, compound-v3/lending, uniswap-v3/dex, jupiter/dex-solana) with fields protocol_id, name, chain, coingecko_id, defillama_pool_id, category, liquidity_risk. Schema per entry: symbol, name, exchange, currency, timezone, sector. KG coverage report reads this file to compute coverage. | (config file; read by KG and scanner components) | N/A |
| Agent LLM Config | args/fathomdesk_config.yaml | FathomDesk agent LLM override configuration. `agent_llm_overrides` maps each agent role to a router function key. Air-gap safe roles (technical_agent, sentiment_agent) use ollama/llama3; high-stakes roles (debate_engine, risk_manager) use Opus; balanced roles (fundamentals_agent, macro_agent) use Sonnet. Read by `tools/fathomdesk/llm_factory.py`. | (config file; read by llm_factory.py) | N/A |
| Broker Adapter | tools/fathomdesk/broker_adapter.py | FathomDesk Alpaca order adapter — stdlib-only, no SDK. Submits limit and stop orders via Alpaca REST v2. Credentials: `ALPACA_API_KEY`, `ALPACA_SECRET_KEY`, `ALPACA_BASE_URL` from .env. **Paper vs. live is decided by the EXPLICIT `ALPACA_TRADING_MODE=paper\|live` env var (default `paper`), never by a URL substring; mode/URL disagreement raises `BrokerConfigError` at construction (nav-plat-02).** Normalizes base URL (strips trailing `/v2` if present). `BrokerAdapter.submit_limit_order(ticker, qty, limit_price, side, tif, *, live_confirmed=False)` and `submit_stop_order(ticker, qty, stop_price, side, *, live_confirmed=False)` — in live mode a submit without `live_confirmed=True` raises `LiveOrderConfirmationError` before any HTTP; paper submits unaffected. Raises `RuntimeError` on HTTP errors. Web-unexposed (no Flask route reaches submit_*). CLI: `--limit-order TICKER QTY PRICE SIDE`, `--stop-order ...`, `--test-paper`, `--confirm-live`. | `python tools/fathomdesk/broker_adapter.py --limit-order SPY 1 10.00 buy` | Alpaca order response JSON |
| PE/NAV Migration | tools/db/migrate_pe_nav.py | Adds PE/NAV columns: `nav_per_share`, `sector_tier` on `ad_fundamental_metrics`; `pe_nav_score`, `implied_roe`, `roe_gap`, `nav_quadrant` on `ad_quality_scores`.
