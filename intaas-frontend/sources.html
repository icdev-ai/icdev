About INTaaS Sources

GDELT — Global Database of Events, Language, and Tone. Free, 65 languages, 15-minute updates, since 1979. Primary data backbone.

MediaCloud — Open-source media research platform. 1B+ stories, hyperlink analysis, academic backbone.

Semantic Scholar — 200M+ academic papers. Provides the "neutral anchor" for fact-checking against peer-reviewed research.

Media Bias/Fact Check — 5,600+ source credibility ratings. Provides per-outlet bias profiles used in scoring.

AllSides — 800+ media bias ratings (left/center/right). INTaaS extends this beyond political axes.
