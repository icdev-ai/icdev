# Capstone Reflection

After your run (or, if you did not run it live, after reviewing your design):

1. **What role performed best?** Which co-worker's output was highest quality, or which would you expect to be, and why?
2. **Where did HITL add value?** What would have been missed without human review?
3. **What would you add?** If you had a 4th co-worker, which role from `args/ace/roles/` would you add, and with what task?
4. **Team vs. solo:** How does the quality of this 3-co-worker run compare to asking a single agent the same questions?

Think your answers through in 200-300 words, with specific examples from your run or design, then press Continue.
