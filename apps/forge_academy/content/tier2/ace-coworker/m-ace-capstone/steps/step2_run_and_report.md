# Capstone Reflection

After completing your pipeline run:

1. **What role performed best?** Which co-worker's output was highest quality?
2. **Where did HITL add value?** What would have been missed without human review?
3. **What would you add?** If you had a 4th co-worker, what role and task?
4. **Team vs. solo:** How does the quality of this 3-co-worker pipeline compare to asking a single agent the same questions?

Write your reflection in 200-300 words. Include specific examples from your pipeline run.
