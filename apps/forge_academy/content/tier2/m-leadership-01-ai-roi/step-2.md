# Build Your ROI Model

An ROI model does not need to be precise to be useful. It needs to be structured enough to expose the key assumptions and surface the conversation worth having.

## The Five-Variable Framework

Work through each variable for the workflow you identified in Step 1.

### 1. Problem / Workflow Target
State the process in one sentence. Be specific about volume, frequency, and current owner.

### 2. Current State Cost Estimate
Estimate annual cost: hours per instance × instances per year × fully-loaded hourly rate.

### 3. AI-Assisted Cost Estimate
Estimate the same output with AI augmentation. Even conservative assumptions (50% time reduction) change the math significantly.

### 4. Implementation Cost
Include: vendor licensing or build cost, integration effort (weeks of engineering × rate), training, and first-year oversight.

### 5. Payback Period
`Payback = Implementation Cost ÷ Annual Savings`

---

## Example: Government Document Review

| Variable | Value |
|---|---|
| Workflow | Contract clause review — 200 contracts/year, 4 hours each |
| Current cost | 200 × 4 hrs × $85/hr = **$68,000/year** |
| AI-assisted cost | 200 × 1.5 hrs × $85/hr = **$25,500/year** |
| Savings | **$42,500/year** |
| Implementation cost | $60,000 (SaaS license + integration + training) |
| Payback period | **~17 months** |
| 3-year net benefit | $42,500 × 3 − $60,000 = **$67,500** |

At 17 months payback with a clear 3-year net positive, this case funds itself.
