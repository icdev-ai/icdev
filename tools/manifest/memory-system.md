| Observation Capture | tools/hooks/observation_capture.py | xrv-mem-02. Bounded per session (`memory_config.yaml: auto_capture.max_per_session`, 200; counted in `.tmp/memory_capture/`, not in the self-flushing buffer). SECOND SINK: `buffer_procedural_patterns` buffers one `procedural` row per chain `pattern_detector` already scored (called by the synthesize reflex on the list it stores; no second miner). | Memory Tier Measure | tools/memory/memory_tier_measure.py | oss2-meas-01. Refuses a verdict below 30 entries (`insufficient_data`) so it can't launder a claim from too little data. Live result (98 entries): 40–64% redundancy → consolidation earns its keep; 0% embedding coverage flagged.
