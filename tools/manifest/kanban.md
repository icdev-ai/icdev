# Kanban System

> Shard of `tools/manifest.md`. See index at `tools/manifest.md`.

## Kanban Tools

| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| DES Audit Logger | tools/kanban/des_audit_logger.py | Append-only DES execution audit trail (NIST AU). Inserts dispatch, completion, verification, and gate_override events into `des_execution_events` table — never UPDATE/DELETE. Class `DESAuditLogger` exposes: `log_dispatch(task_id, skill, inputs, executor, source)`, `log_completion(task_id, status, outputs, duration_ms)`, `log_verification(task_id, signals)`, `log_gate_override(task_id, reason, operator)`. Table: `des_execution_events` (migration 065). | `--query --task-id <id> [--json]` | Event ID string / JSON list of events |
| State Machine | tools/kanban/state_machine.py | Kanban task state transition engine — enforces valid status flows (scheduled→in_progress→done/failed) with guard-22 verification gate | Task ID, target status | Transition result |
| Task Factory | tools/kanban/task_factory.py | **Canonical, deadlock-safe task creation path — all seeders/creators MUST use this, never raw INSERT.** `create_tasks(project_key, [TaskSpec...])` validates the batch (via seed_validator), defaults status to `backlog`, REFUSES `scheduled` without `scheduled_at` (the deadlock state), writes scalar + junction (`kanban_task_deps`) deps, is idempotent, auto-registers the project. PG + SQLite via storage shim. See `tools/kanban/SEEDING.md`. | `create_tasks(project_key, tasks, *, dry_run, strict, register_project, llm_grade)` | `SeedReport{seeded, skipped, healed, warnings}` |
| Seed Validator | tools/kanban/seed_validator.py | Quality + integrity gate for a task batch: structural (id convention, deps resolve, no cycles, status legal, scheduled⇒scheduled_at), deterministic content (≥200 chars, names file paths, acceptance criteria, test plan), and LLM rubric (Haiku ≥70; degrades to deterministic-only offline). Used by Task Factory (strict) and as a standalone pre-seed gate. | `--gate (--file spec.json \| --project KEY) [--no-llm] [--json]` | Scorecard / JSON; exit 1 on failure |
| Limbo Reconcile (reflex) | tools/genesis/reflexes/kanban.py:_reconcile_limbo_tasks | Self-healing sweep run every scheduler cycle — converts `scheduled`+NULL-`scheduled_at` rows (undispatchable; deadlock the chain) to `backlog`, logs dangling deps. Backstop so a bad seeder/manual SQL self-corrects within ~60s. | `_reconcile_limbo_tasks(conn=None)` | list of healed task ids |
| Done-Artifact Auditor | tools/kanban/done_artifact_auditor.py | Post-process for every batch / project-in-flight: verifies `done` tasks actually shipped. Parses artifact file paths + `Verify:` commands from each done task's description, checks they exist on the working tree (`--git` also flags untracked-on-branch). Flags done-tasks with missing artifacts (the ACE 42/42-done-but-unbuilt failure). Never mutates status — reports only. Funcs: `extract_artifact_paths`, `audit_task`, `audit_tasks`, `audit_project`, `audit_all`, `summarize`. | `--all` or `--project <id>` `[--json] [--git] [--gate]` | Markdown/JSON report; `--gate` exits 1 on any missing artifact |
| Done-Artifact Audit reflex | tools/genesis/reflexes/done_artifact_audit.py | Genesis SUPPORT reflex (6h) wrapping the auditor — sweeps every project-in-flight from `args/projects.yaml` and logs/returns done-tasks whose claimed artifacts are missing. Registered in `reflex_registry.py` REGISTRY + `daemon.py` REFLEX_NAMES + `args/genesis_config.yaml`. Activates on next daemon restart. | `run(config, trust)` (daemon-dispatched) | `{success, metric_value=flagged_count, details}` |
| Source Stats | tools/kanban/source_stats.py | Kanban task source statistics aggregator — counts tasks by source/type for dashboard metrics | --json | JSON stats dict |
| Kanban Verify | tools/kanban_verify.py | Runs coherence gate and records detailed failure reason in `kanban_verifications`. Parses coherence_checker.py JSON output, extracts the first failing rule/file/line, and stores it as the `reason` field instead of the opaque "unknown". | `--task-id <id> [--json] [--dry-run] [--changed-files f1,f2]` | JSON verification result |
| AI Skills Gap Seed | tools/kanban/seed_aisg.py | Seed script for the AI Skills Gap Enablement Platform (aisg- prefix). Queues four-phase Kanban initiative: Phase A (Zero-to-AI wizard + role views), Phase B (Guided AI Curriculum + pattern library), Phase C (No-Code AI Customization + visual builder), Phase D (AI Workforce Multiplier Metrics + ROI dashboard). Sets depends_on_task_id and scheduled_at on all seeded tasks. | python tools/kanban/seed_aisg.py [--dry-run] [--json] | {seeded, tasks[], dry_run} |
