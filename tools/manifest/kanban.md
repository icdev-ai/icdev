| Flow Control | tools/kanban/backpressure.py | Bounds finished-but-UNREVIEWED output in the autonomous build loop (clx-flow-01). `MAX_IN_PROGRESS` caps tasks that are *executing*; a task moving to `pr_opened` stops being counted, frees a slot, and the loop dispatches more — so open PRs stack without limit, conflict with each other, and defer the human review that is the loop's feedback signal. Counts `pr_opened`/`ci_failed`/`changes_requested`/`merge_conflict`/`validating` and narrows or holds dispatch. OFF unless `KANBAN_BACKPRESSURE_ENABLED=1` (throttling throughput is an operator's call); ceiling via `KANBAN_MAX_UNREVIEWED` (default 3). Fails OPEN — a counting error never wedges dispatch. Wired into `promote_backlog_to_scheduled`'s slot calculation. | `apply_backpressure(slots)`, `count_unreviewed()`, `status()` | int / dict |
