## AI Augmentation Canvas (AAC)

Scans source repositories for AI-augmentable code patterns and produces a scored, phase-banded modernization roadmap. Primary path: Semgrep CLI (multi-language, 8 pattern rules). Air-gap fallback: Python `ast` walker for `.py` and a regex/tree-sitter path for `.cs`. Scores each opportunity using a deterministic weighted multi-criteria model (`args/aac_config.yaml`). Persists results to PostgreSQL (default) or SQLite (`data/aac_canvas.db`). Integrates with AIMC (`/ai-ml/models/new`) and AADC (`/agentic-ai/topologies/new`) for downstream tooling. Feature flag: `ICDEV_AAC_ENABLED`. IQE collections: `ai_augmentation.opportunities`, `.scans`, `.roadmaps`. Classification: CUI // SP-CTI.

| Opportunity Scorer | tools/ai_augmentation/opportunity_scorer.py | Deterministic weighted multi-criteria scorer. Sub-scores: `value = usage_freq*0.40 + task_complexity*0.35 + automation_deficit*0.25`; `feasibility = data_avail*0.40 + il_model_exists*0.35 + (1-integration_complexity)*0.25`; `risk = reversibility*0.40 + compliance_impact_inv*0.35 + (1-dep_complexity)*0.25`; `composite = value*0.45 + feasibility*0.35 + (1-risk)*0.20`. IL-level penalty applied to compliance when `il_level=il5/il6`. Weights hot-reloaded from `args/aac_config.yaml`; degrades to built-in defaults on missing file. | Roadmap Generator | tools/ai_augmentation/roadmap_generator.py | Builds a prioritized roadmap from scored opportunities. | LLM Threshold Advisor | icdev/tools/ai_augmentation/generators/llm_threshold_advisor.py | AAC generator for `hardcoded_threshold → llm_generation` opportunities.
