## Migration Version Uniqueness (2026-07-26)
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Migration Versions | tools/db/migration_versions.py | Detects duplicate migration version numbers. `MigrationRunner` keeps only the FIRST migration per version, so same-version siblings are skipped permanently and silently — the root cause of a large share of the tables missing from live databases. Grandfather list: `args/migration_duplicate_versions.yaml`, where **every entry must carry a reason** (`- <name>: "<why safe>"`); an unexplained entry fails the gate. The scan reads the filesystem, so a renamed migration leaves its old directory behind in every pre-existing checkout holding only `__pycache__`; such directories track no file in git and are excluded from the version scan and reported separately as stale local artifacts, never as collisions. Public API: `find_duplicates()`, `shadowed_migrations()`, `check()`, `load_allowlist()`, `load_allowlist_reasons()`, `unexplained_entries()`, `stale_directories()`, `stale_directory_message()`. | `--json`, `--gate`, `--shadowed` | JSON `{duplicate_versions, new_violations, unexplained_entries, shadowed_count, stale_directories, passed}` |
| Shadowed Migration Audit | tools/db/shadowed_migration_audit.py | Answers whether a grandfathered collision is actually harmless, by BUILDING rather than reading: classifies every shadowed migration against four oracles (fresh PostgreSQL via `bootstrap_pg.py`, fresh SQLite via `init_icdev_db.py`, declaring source in the tree, long-lived DB). Found 6 real gaps in 60 grandfathered entries — incl. `dashboard_users.role` rejecting four RBAC roles on PostgreSQL, a defect invisible to a table/column diff. Also reports where the gate's shadowing view disagrees with the runner's, and `icdev/` mirror drift. Report: `docs/reference/shadowed-migration-audit-2026-08-03.md`. Public API: `audit()`, `runner_shadowed()`, `runner_invisible()`, `declaring_sources()`, `extract_objects()`, `pg_schema()`, `fresh_schema()`. | `--json`, `--gaps`, `--fresh-db <path>`, `--fresh-pg-dsn <dsn>` | JSON `{counts, findings[], fresh_pg, fresh_sqlite, live_db, mirror}` |
