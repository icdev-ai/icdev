| Retention Sweep Reflex | tools/genesis/reflexes/retention_sweep.py | 24h config-driven retention/archival framework (crx-db-03). Reads `args/retention_policies.yaml` mapping each high-churn operational table → `{keep_days, strategy: prune|archive, timestamp_column, id_column, archive_dest}`. Non-append-only tables (e.g. `agent_execution_traces`, `kanban_verifications`, `a2a_task_history`) are pruned past `keep_days` under a per-run `max_rows_per_table` cap; **append-only/audit tables are archive-to-cold ONLY (never pruned)** — enforced by parsing `APPEND_ONLY_TABLES` from `.claude/hooks/pre_tool_use.py` at runtime and FAILING CLOSED (archive-only) if unreadable. RAG/observability/PDC self-managed retention is excluded. `dry_run` defaults TRUE; every action logged to the append-only `retention_action_log`. | `run(ctx, conn)` called by Genesis daemon; `ctx={'dry_run': False}` to execute; `apply_retention()` is the pure/testable engine | JSON `{status, dry_run, total_affected, tables{}, metric_value}` |

| Calibration Report | tools/genesis/harness/calibration_report.py | Reports whether confidence predicts correctness, **per rule** — the actionable cut. Confidence in the awareness lens is not computed per prediction; it is a per-rule constant from `awareness_config.yaml`, so a band is a set union of unrelated rules (the live 0.9 band is 19 rows of `tool_not_in_manifest` + 1 of `route_not_listed`). Reads evidence where it actually is: the ORGANIC join `oracle_predictions.outcome ~ 'promoted:task-%'` → `kanban_verifications.result` (**biased** — only what the system chose to promote) and SAMPLED `harness_eval` rows under `sampled:*` (**unbiased**, from `confidence_sampler`). The two are never pooled. Renders `UNMEASURED` below `MIN_CALIBRATION_SAMPLES` rather than a point estimate, tracks `bypassed` as non-evidence (never a failure), and flags rules whose constant was edited (mixed `claimed_values`). Report-only — never moves a threshold. States when `harness_eval` is empty, since `check_gates` reads it and an empty table renders as a green gate. | `--json`; `build_report(conn)` / `render(report)` | JSON `{harness_eval:{total,labelled}, organic:{provenance,joined,rules[]}, sampled:{…}, min_samples}` |
| Code Reload | tools/genesis/code_reload.py | Lets a long-lived daemon pick up its own merged code changes without a human restart. Watches the mtimes of every already-imported in-repo module (via `sys.modules`, so the watch set is exactly the code the process actually loaded) and `os.execv`s the process in place when any of them changes — re-exec rather than exit, because supervision on this deployment is uneven and a daemon that exits under an unwatching launcher is worse than one running stale. | (library, called from daemon loops) | Re-exec on change; no-op otherwise |
