# BDC cATO Twin (Phase BDC-1)

> Shard of `tools/manifest.md`. See index at `tools/manifest.md`.
>
> Continuous Authority to Operate digital twin — snapshot writer, IQE query surface, continuous reflex monitor, and OSCAL export for multi-framework compliance evidence. Phase 1-4 implementation per `docs/briefs/digital-twin-market-canvas-implementation-plan.md`.

## BDC cATO Twin Core
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| cATO Snapshot Writer | tools/boundary_canvas/cato_snapshot.py | [Phase 1] Freeze full cross-framework control state into `compliance_snapshots` at assessor-run end. Canonical grain: control × project × framework × timestamp → implementation_status + evidence_ref. Append-only; never updates existing rows. | (library) `snapshot_compliance_state(project_id, framework_id, timestamp=None)` | `{snapshot_id, project_id, framework_id, timestamp, control_count, evidence_count}` |
| cATO IQE Adapter | tools/iqe/adapters/boundary.py | [Phase 1] Registers IQE collections against `compliance_snapshots`: `boundary.snapshots`, `boundary.controls` (project_controls + compliance_controls JOIN), `boundary.violations` (poam_items). DSL example: `foreach ctrl in framework('FedRAMP Moderate').controls where ctrl.status != 'satisfied' select ctrl.id, affected_projects(ctrl)`. | `import tools.iqe.adapters.boundary` | Collections registered on module-level `Executor`; returns result set dicts |
| cATO Continuous Monitor | tools/boundary_canvas/cato_continuous_monitor.py | [Phase 1] Genesis reflex job (6h cadence): re-executes seed IQE rule set on each new snapshot, diffs vs previous snapshot, emits POA&M entries for net-new violations, and resolves auto-closed items. Integrates with `cato_monitor.py` for evidence freshness scoring. | Genesis reflex config dict | `{violations_new, violations_resolved, poam_entries_created, freshness_score}` |
| cATO Readiness Scorer | tools/boundary_canvas/cato_readiness.py | [Phase 1 · bdr-feat-2] Computes a 0–100 cATO readiness composite for a boundary design from four weighted components: control coverage (`compliance_twin_snapshots`), open linked POA&M count (`compliance_twin_violations`→`poam_items`), ISA expiry health (`bd_isa_tracker`, canvas DB), and snapshot freshness (exponential decay). Weights/bands/half-life in `args/bdc_readiness_config.yaml` (safe default fallback; no hardcoded weights). All analytics computed in Python from plain-column reads. Missing tables/data degrade to `score=None`, `band="unknown"` — never a 500. Route: `GET /boundary/api/cato/readiness/<design_id>`; tile on `twin.html`. | `compute_readiness(design_id, project_id=None, *, conn=None, canvas_conn=None, config=None)` / CLI `--design-id, --project-id, --json` | `{design_id, project_id, score, readiness_score, band: green(≥80)|amber(≥50)|red|unknown, components{control_coverage,poam,isa_expiry,freshness}, weights}` |
| OSCAL cATO Exporter | tools/boundary_canvas/oscal_cato_exporter.py | [Phase 2] Generates OSCAL SSP, POA&M, Assessment Results, and Component Definition from `compliance_snapshots` state. Machine-readable FedRAMP 20x artifacts. Delegates to `tools/compliance/oscal_generator.py` for schema compliance. | `--snapshot-id, --artifact-type ssp|poam|ar|cd, --format json|xml, --output-dir` | OSCAL artifact path |
| Crosswalk Drift Detector | tools/boundary_canvas/crosswalk_drift.py | [Phase 3] Compares control mappings across framework pairs (NIST 800-53 ↔ CMMC, FedRAMP, 800-171, IL4/5/6, CJIS, HIPAA, SOC2, PCI DSS, ISO 27001). Surfaces "AC-2 satisfied in NIST but not_satisfied in CMMC" drift events. | `--snapshot-id, --framework-pairs, --json` | `[{framework_src, framework_tgt, control_id, status_src, status_tgt, drift: true|false, recommendation}]` |
| cATO Dashboard API | tools/dashboard/api/cato.py | [Phase 4] Flask Blueprint: `GET /boundary/cato/projects` (ATO posture per project), `GET /boundary/cato/project/<id>` (drill-down: control status + evidence + remediation steps), `POST /boundary/cato/simulate` (what-if: apply policy delta, measure compliance delta). Reads only from `compliance_snapshots` + `cato_evidence`. | Blueprint routes | JSON: `{project_id, framework_id, readiness_score, red_controls[], evidence_count, days_since_assessment}` |
| BDC cATO Digital Twin Facade | tools/boundary_canvas/twin.py | Unified facade for BDC cATO twin operations: snapshot freeze, policy-delta simulation (readiness score + violations), cross-framework crosswalk drift, and OSCAL export. Delegates OSCAL to `oscal_cato_exporter.py`. All DB writes via `get_connection()`. | (library) `take_snapshot(project_id, framework_id)`, `simulate_delta(project_id, delta, framework_id, baseline_snap_id)`, `crosswalk_drift(project_id, fw_src, fw_tgt)`, `export_oscal(project_id, snapshot_id, artifact_type)` | `{snapshot_id, ...}` / `{simulation_id, rating, score, violations, ...}` / `{drifts, total}` / `{artifact_type, path, snapshot_id}` |

## BDC cATO Twin DB Tables
| Table | Purpose |
|-------|---------|
| `compliance_snapshots` | Core cATO primitive. Append-only. Columns: `snapshot_id` (UUID PK), `project_id`, `framework_id`, `control_id`, `implementation_status` (satisfied/not_satisfied/partially_satisfied/not_applicable/planned), `evidence_ref`, `taken_at`. Indexed on `(project_id, framework_id)`, `(control_id, implementation_status)`, `(taken_at)`. |
| `cato_iqe_rules` | Seed IQE rule set (20 FedRAMP Moderate + 10 CMMC rules). Columns: `rule_id`, `framework_id`, `dsl_text`, `severity` (critical/high/medium/low), `enabled`. |
| `cato_violations` | Violation log from continuous monitor reflex. Columns: `violation_id`, `snapshot_id`, `rule_id`, `control_id`, `project_id`, `detected_at`, `resolved_at` (nullable), `poam_ref`. |
