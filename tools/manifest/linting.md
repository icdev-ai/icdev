## Linting
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| SQLite3 Connect Linter | tools/lint/sqlite3_connect_linter.py | Scans tools/ for bare sqlite3.connect() calls that bypass get_connection(); exempt files: tools/db/storage.py, init_icdev_db.py, migration_runner.py, backup_manager.py, */init_db.py; lines with # sqlite3-ok are skipped | --path, --json, --gate | Violation list; exit 1 on --gate + violations |
| PG Portability Linter | tools/lint/pg_portability_linter.py | AST-scans runtime tools/ for PG-unsafe SQLite-dialect SQL the translator should not handle at runtime: json_each, nested json_array_length(json_extract(...)) (high); standalone json_extract/json_array_length + PRAGMA (medium); runtime sqlite3.connect (high, reuses sibling exemptions). Ignores comments/docstrings; excludes init_db.py/seeds/migrations/schema/lint/tests; inline `# pg-ok` opt-out. Baseline allowlist (tools/lint/pg_portability_baseline.json) snapshots existing debt; only NEW high findings fail. | --path, --files, --json, --baseline, --write-baseline, --gate | {file,line,pattern,severity,fix} findings; exit 1 on high-severity above baseline |
| INSERT Column Linter | tools/lint/insert_column_linter.py | swp-scan-01 detector: AST-parses every *static* `INSERT INTO <table> (<columns>)` under tools/ and checks the named columns against the LIVE schema (information_schema on PG, PRAGMA table_info on SQLite) — `CREATE TABLE IF NOT EXISTS` never alters an existing table, so source DDL cannot answer this. Recovers implicitly-concatenated string literals; skips statements whose column list contains an f-string. Kinds: `column_absent` (table exists, column does not) and `table_absent` (out of scope, not gated). Excludes migrations/, tests/, __pycache__/. Triage: docs/database/insert-column-schema-parity.md; accepted set pinned in tests/test_insert_column_schema_parity.py. | --json, --kind, --baseline, --triage, --gate | {stats, total, above_baseline, findings[]}; exit 1 on findings above baseline with --gate, exit 2 if the live schema is unreadable |
| Citation Type Linter | tools/lint/citation_type_linter.py | cxo-trust-02 gate: scans `tools/` for `citation_type="..."` literals whose value is absent from `tools/provenance/citation_types.py::CITATION_TYPES`. `register_citation()` validates the vocabulary BEFORE the INSERT and raises `ValueError`, which every caller swallows — so an unknown value writes nothing, silently, forever. Two subsystems shipped that: cortex governance (`"cortex"`, 0 of 285 registry rows while its gate logged `warn`) and GovChain asset_ledger (`"asset_token"`, `anchor_status` stuck at `skipped`). Imports the vocabulary rather than copying it. Skips `tests/` (a test may assert a bogus type is rejected), `migrations/`, dynamic `citation_type=<var>`, and its own file; single lines opt out with `# citation-type-ok`. | --path, --json, --gate | {violations[], count, valid_types, clean}; exit 1 on violations with --gate |
| Canvas Table Collision Auditor | tools/lint/canvas_table_collision_auditor.py | PGP-sch-03 detector: parses `tools/<canvas>/db/init_db.py` CREATE TABLE statements and compares against live `information_schema.columns`; groups by table name, flags divergent (same name + different column signatures - high severity, must namespace per pgp-sch-02) vs benign-shared (same name + identical columns - info only). Live PG scan reads scope=public by default. Feeds pgp-sch-02 and pgp-gate-01. | --scope, --json, --md, --canvas | JSON {static_module_audit, live_pg_audit} or markdown summary; exit 1 on divergent_count > 0 |

| Violation Sensor | tools/quality/sensor.py | Deterministic sensor over `review_loop.py` (clx-sense-01). Returns structured `Violation` records (file, line, rule, gate, severity, fixable, file_scoped) ranked blocking-first, so a controller can pick what to fix next from measured deviation instead of prose. Runs the review loop with autofix DISABLED and one iteration — a sensor that repairs what it measures cannot inform the decision. `file_scoped=False` marks repo-level findings (the coherence gate reports checks, not paths). No new scanner and no ast-grep dependency: it adapts the gates ICDEV already runs. | `--base REF`, `--staged`, `--json` | `{count, blocking, violations[]}` |
