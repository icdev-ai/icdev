# Strategos

> Shard of `tools/manifest.md`. See index at `tools/manifest.md`.

## Strategos

| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| GitLab OSINT Collector | tools/strategos/gitlab_osint_collector.py | Standalone GitLab CI runner script. Reads internet-tier sources from args/strategos_config.yaml (or strategos_osint_sources.yaml), fetches RSS feeds, deduplicates via sha256, and writes two artifacts: osint_signals.json (sg_raw_signals array, max 500) and kg_delta.json (entity mentions: unit names, locations, equipment). Any source failure is logged and skipped. Always exits 0. | --output-dir PATH, --json | osint_signals.json {sg_raw_signals, count, run_at}; kg_delta.json {entities, run_at} |
| Tier Resolver | tools/strategos/tier_resolver.py | Resolves active OSINT and executor tiers at runtime. OSINT: INTERNET → GITLAB → FILE_INBOX → NONE. Executor: CLAUDE_CLI → GITLAB → OLLAMA_LOCAL. Caches 5 min; logs tier changes. Used by osint_harvester, kanban_scheduler, and external importers. | --json, --no-cache | TierStatus JSON (osint_tier, exec_tier, gitlab_reachable, file_inbox_count, ollama_reachable, resolved_at) |
| OSINT Harvester | tools/genesis/reflexes/strategos/osint_harvester.py | Three-tier OSINT signal harvester (INTERNET→GITLAB→FILE_INBOX→NONE). Deduplicates via sha256. Writes sg_raw_signals + sg_raw_signals_audit. Handles RSS, Telegram, snscrape, GitLab CI artifacts, and file inbox JSON/TXT. | --json | {success, metric_value, details{tier, signals_harvested, duplicates_skipped, errors}} |
| GDELT Importer | tools/strategos/gdelt_importer.py | GDELT 2.0 narrative-events bulk importer. Downloads export CSV ZIPs, filters to Ukraine/Taiwan AOIs (country code + lat/lon bbox), and upserts into sg_conflict_events (event_type=narrative_event, source=gdelt). Deduplicates via (source, external_id) unique index. | --file, --date YYYYMMDD, --days N, --dry-run, --json | {dry_run, files_attempted, files_ok, total_aoi_rows, by_aoi, inserted, skipped_duplicates} |
| STIX Importer | tools/strategos/stix_importer.py | STIX 2.1 / CERT-UA cyber threat bundle importer. Parses campaign, intrusion-set, threat-actor, malware, tool, and indicator objects. Maps indicator patterns and relationship chains to MITRE ATT&CK technique IDs (T-codes). Writes to sg_conflict_events (event_type=cyber_op) and canvas_kg_nodes/edges (CyberOperation, ThreatActor, Malware, Tool, Indicator node types). Deduplicates via (source, external_id) unique index. | --file PATH, --source LABEL (default: stix; use cert-ua for CERT-UA feeds), --dry-run, --json | {dry_run, source, bundle_id, objects_found, by_type, inserted, skipped_duplicates, kg_nodes_written, kg_edges_written} |
| Behavior Pattern Lens | intelligence/oracle/lenses/behavior_pattern.py | Adversary behavior pattern lens for SIOEngine (lens_id=behavior_pattern). Reads sg_conflict_events (30d): escalation_velocity, pattern_repetition, deception_indicators. Score = weighted avg ×10. Writes to sg_sio_assessments. | python intelligence/oracle/lenses/behavior_pattern.py | {score, confidence, nato_reliability, narrative, sub_scores} |
| Threat Posture Lens | intelligence/oracle/lenses/threat_posture.py | Threat posture lens for SIOEngine (lens_id=threat_posture). Reads sg_conflict_events + sg_raw_signals: adversary_mobility, force_concentration, offensive_indicators. Score = weighted avg ×10. Writes to sg_sio_assessments. | python intelligence/oracle/lenses/threat_posture.py | {score, confidence, nato_reliability, narrative, sub_scores} |
| Intent Assessment Lens | intelligence/oracle/lenses/intent_assessment.py | PMESII-PT historical precedent matcher (lens_id=intent_assessment). Compares 7-dim PMESII-PT vector vs 15 seeded historical cases via cosine similarity. Returns top-3 precedents, score 0–10, NATO reliability. Writes to sg_sio_assessments + historical_cases. | python intelligence/oracle/lenses/intent_assessment.py [P M E S I I2 PT] | {current_vector, top_matches, score, confidence, nato_reliability, narrative} |
| Convergence Lens | intelligence/oracle/lenses/convergence.py | Cross-domain convergence lens for SIOEngine (lens_id=convergence). Reads latest scores from sg_sio_assessments for peer lenses, computes std_dev, convergence_score = 10-(std_dev×2). I&W triggered when convergence>7.5 AND avg>6.0. | python intelligence/oracle/lenses/convergence.py | {score, confidence, nato_reliability, narrative, iw_triggered, lens_scores} |
| SIO Engine | intelligence/oracle/sio_engine.py | Strategic Intelligence Oracle orchestration engine. Runs all 4 lenses in sequence, computes composite_score (weighted avg), returns OracleAssessment dataclass. CLI --run-all --json. Also exposes get_latest_assessment() for dashboard API. | python -m intelligence.oracle.sio_engine --run-all --json | OracleAssessment JSON: {lenses, composite_score, iw_triggered, top_narrative, timestamp} |
| Targeting Package Optimizer | tools/strategos/targeting_package_optimizer.py | Greedy hill-climb + 1-opt local search for optimal interdiction package. Objectives: maximize_blast_radius, minimize_time_to_effect, maximize_endurance_delta. Synergy: delta_blast(A+B)−delta_blast(A)−delta_blast(B). Returns OptimalPackage: nodes, combined_blast_radius, blast_pct, time_to_effect_p50_days, endurance_delta_months, marginal_value_per_node, synergy_pairs. | --budget N --objective X --theater Y --json | OptimalPackage JSON + computed_at + params |
| OSM Logistics Importer | tools/strategos/osm_importer.py | Imports Ukraine rail/road/bridge/port infrastructure from an OSM GeoJSON export into sg_entities (entity_type=logistics_node). Classifies features by OSM tags (bridge→bridge, railway→rail, port amenity/landuse/man_made/waterway→port, highway→road). Computes geometry centroids. Seeds vulnerability_score=0.5; domain scorer updates scores later. Deduplicates via UNIQUE(source, external_id). Requires migration 061_sg_entities. | --file PATH [--node-types rail,road,bridge,port] [--aoi ukraine] [--dry-run] [--json] | {dry_run, file, aoi, total_features, by_node_type, inserted, skipped_duplicates} |
