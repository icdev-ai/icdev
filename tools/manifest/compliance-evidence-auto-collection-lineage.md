| Evidence Collectors for customer environments | tools/evidence_collectors/service.py | icx-ent-02. Read-only collectors for a CUSTOMER system: cloud configuration (`collectors/aws_config.py`, AWS Config Describe calls, SigV4 in `sigv4.py`), identity provider (`collectors/oidc_scim.py`, OIDC Discovery 1.0 + SCIM 2.0 /Users), endpoints (`collectors/intune.py`, Intune via Microsoft Graph), SIEM (`collectors/splunk.py`, Splunk REST). One read-only transport (`transport.py`: GET or a named read POST, the configured host only, no redirects, https or loopback http). Credentials by reference only (`credentials.py`: `keyring:`/`vault:`; a literal is refused on load). Observations carry observed_at, collector, system and a freshness budget; `bundle.py` judges objectives by the reviewed mapping in `args/evidence_collectors.yaml` (stale/future/timeless = unverified, never met from absence) and builds one `icos-objective-evidence/v1` report per system per run against the pinned `context/icos/objective-evidence.schema.json`. Prepare (anyone or an agent) then publish (a person of the system's org, never the preparer: `decl-wft-ec-evidence-publish`) in the append-only, hash-chained `ec_events` (`ledger.py`, on `tools/common/stream_chain.py`). Page `/evidence-collectors/`; MCP `evidence_collectors_status` (read), `evidence_collectors_prepare` (draft). | --system, --agent, --out (cli.py) | icos-objective-evidence/v1 report |
| Evidence Collectors CLI | tools/evidence_collectors/cli.py | `python -m tools.evidence_collectors.cli systems\|check-config\|collect\|prepare\|export`. Acts as an agent at the MCP marking; never publishes; `export` writes only a published report. | command, --system, --agent, --out, --json | JSON |
