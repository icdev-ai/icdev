| Manifest Merge Rehearsal | tools/git/manifest_merge_rehearsal.py | kax-conflict-03. Scripted two-branch git rehearsal that MEASURES which `tools/manifest/` layout survives the observed edit pattern (unrelated tasks each registering a new tool under the same topic). Builds a throwaway repo per scenario, cuts N branches, merges them back, and reports conflict / entries-kept / duplicate-entries. Layouts: `table-row` (baseline), `heading-block`, `union` (`.gitattributes merge=union`), `per-tool-file`. Runs both merge paths — `worktree` (local `git merge`) and `merge-tree` (bare `git merge-tree --write-tree`, the plumbing a forge runs server-side to compute mergeability), because a layout that is clean only in the worktree path still shows a PR as conflicted. Measured 2026-08-08: table-row and heading-block CONFLICT in both paths; union and per-tool-file are clean in both at 2/3/5 branches. Backs the `merge=union` decision recorded in `.gitattributes`. | --layout, --mode {worktree,merge-tree,both}, --branches, --keep, --json | Per-scenario conflict report + `conflict_free_layouts` |

| CI Test List Merge Rehearsal | tools/git/ci_test_list_merge_rehearsal.py | kax-conflict-07. Scripted multi-branch git rehearsal that MEASURES whether N branches each adding a gated test file can merge without a human. Layouts: `inline` (the CONTROL — allowlist as a line-continuation chain inside .github/workflows/icdev-ci.yml), `external` (moved to args/ci_test_files/core.txt, no merge driver), `external-union` (the shipped shape, `merge=union`). Runs both merge paths — `worktree` (local `git merge`) and `merge-tree` (bare, forge-side). Measured 2026-08-09: inline and external CONFLICT in both paths at 2/3/5 branches; external-union is clean in both with every entry kept. `--gate` also fails if the `inline` control stops conflicting, so a rehearsal that no longer reproduces the problem cannot report success. `--repo .` rehearses against a clone and the real shipped list. | --layout, --mode {worktree,merge-tree,both}, --branches, --repo, --keep, --gate, --json | Per-scenario conflict report + `conflict_free_layouts` |
| Gated Test List Resolver | tools/ci/gated_test_list.py | kax-conflict-07. Resolves the CI pytest allowlists in args/ci_test_files/*.txt that used to be inlined in icdev-ci.yml, and re-earns the "gate cannot silently shrink" property outside the YAML: `--check` exits 1 when the list is missing, EMPTY, below its recorded floor, names a path absent from the checkout, or lists a path twice (what a careless union merge leaves behind). `--extract-workflow` parses the inline pytest chains out of an arbitrary workflow file, which is how the before/after "no entry changed" diff was produced. | --list {core,windows}, --check, --print, --out, --root, --json, --extract-workflow, --job, --min-targets | Resolved target list / validation report |
