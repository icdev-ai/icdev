## ICDEV Cortex (Unified AI Facade)
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Cortex Schemas | tools/cortex/schemas.py | Unified normalization contract for the Cortex facade: Citation, CortexSearchResult (score 0-1, backend in {rag,graph,dic,kb}), CortexResult (structured payload in .data), CortexContext (tenant_id + classification, RLS-ready), GovernanceReport. All dataclasses round-trip via to_dict()/from_dict(). Mirrored to icdev/tools/cortex/. | dataclass construction / dicts | Normalized dataclass instances / JSON-safe dicts |
| Cortex Analyst | tools/cortex/analyst.py | Unified NL ask-your-data endpoint (`cortex.ask(question, mode, ctx)`), IQE primary + NL→SQL fallback. mode="auto": IQE first (resolve collections → nl_to_iqe → authorize → execute), transparently falling back to the dashboard NLQ pipeline (tools/dashboard/nlq_processor.py) when IQE cannot resolve/translate/authorize (never on execution failures or when canvas=/collections= pinned scope); mode="iqe"/"nlq" pin one engine. Shared pre-execution safety layer on BOTH paths: injection screen on the raw question (deterministic SQL-attack shapes + tools/llm/gateway.py check_text), SELECT-only + single-statement enforcement (nlq_processor.validate_sql), and a table allowlist built from component-registry iqe: collections via get_iqe_mapping() (dotted name + dots→underscores table form). Rejections are audited (nlq_queries status=blocked) and raised as CortexQueryBlocked. Tenant/classification from CortexContext thread into the DB connection via SecurityContext (IQE path). Mirrored to icdev/tools/cortex/. | question, mode ("auto"/"iqe"/"nlq"), CortexContext, canvas/collections/conn kwargs | CortexResult (text summary, .data rows + executed iqe/sql, analyst citations, provider "iqe"/"nlq"), CortexQueryBlocked on safety refusal, CortexAnalystError otherwise |
| Cortex API facade | tools/cortex/api.py | Stable import surface for Cortex consumers: re-exports ask(), CortexAnalystError, CortexQueryBlocked, and all schemas. Later ctx-* epics add search()/complete() alongside. Mirrored to icdev/tools/cortex/. | imports | public Cortex API |
