| Cortex Package Facade | tools/cortex/__init__.py | Single import surface for the Cortex facade — `from tools.cortex import complete, classify, extract, search, classify_route`, the schema dataclasses (Citation, CortexContext, CortexResult, CortexSearchResult, GovernanceReport), the air-gap invariant (assert_airgap_ready, airgap_active, CortexAirgapError, AIRGAP_ENV_VAR), config loading (load_cortex_config, resolve_cortex_config_path), and the CORTEX_* routing-function/backend/strategy constants. `__all__` is the authoritative public API; anything not exported there is internal. | Cortex API (complete/classify/extract) | tools/cortex/api.py | First 3 of 7 facade functions over LLMRouter: complete(prompt), classify(text, labels) with deterministic query_classifier degradation when the router raises, extract(text, schema) with output_schema + fenced-JSON parsing. | Cortex Config + Air-Gap Invariant | tools/cortex/config.py | load_cortex_config() reads args/cortex_config.yaml (search strategy_weights/rrf_k/crag_threshold/timeouts, governance fail_closed/skip_grounding_for_plain_complete, analyst nlq_fallback_enabled) deep-merged over defaults, mtime-cached; $ICDEV_CORTEX_CONFIG overrides. assert_airgap_ready() verifies every cortex_* routing chain in args/llm_config.yaml keeps a local ollama-tier (no api_key_env) model, raising CortexAirgapError listing missing entries. airgap_exclusions() honors ICDEV_AIRGAP=1 / CortexContext.air_gap by excluding all cloud model_ids so LLMRouter resolves local-only. Mirrored to icdev/tools/cortex/. | optional config path / CortexContext | dict config; None or CortexAirgapError; list of excluded model_ids |
| Cortex Search Adapters | tools/cortex/search_service.py | Backend adapters normalizing the four native search shapes into CortexSearchResult: search_rag (RAGRetriever, tenant-scoped), search_graph (graph_rag.retrieve, read-only sqlite backend, peak-normalized scores), search_dic (DICSearchEngine, clearance-aware, clearance_required preserved), search_kb (search_knowledge keyword KB). Each adapter is exception-isolated (failure logs + returns []); search_all fans out and merges score-sorted. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx: CortexContext) | list[CortexSearchResult] |
| Cortex Strategy Router | tools/cortex/search_service.py | Agentic routing layer of cortex.search(): classify_route() labels queries (pattern rules for exact_term->kb, relational->graph, document->dic; RAG taxonomy classifier for factual->rag vs ambiguous->parallel fan-out) and search() runs the selected backends via ThreadPoolExecutor with per-backend timeouts from args/cortex_config.yaml (slow backend abandoned, partial results returned). strategy= override (rag/graph/dic/kb/auto/all) bypasses classification; ctx.domain intersects backend selection and records collection scope (ctx-canvas-04 hook). Every result records the decision in .strategy and metadata.router. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx: CortexContext, strategy, config) | list[CortexSearchResult] with routing metadata |
