## ICDEV Cortex (Unified AI Facade)
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Cortex Schemas | tools/cortex/schemas.py | Unified normalization contract for the Cortex facade: Citation, CortexSearchResult (score 0-1, backend in {rag,graph,dic,kb}), CortexResult (structured payload in .data, TRUST labels in .metadata), CortexContext (tenant_id + classification, RLS-ready), GovernanceReport. All dataclasses round-trip via to_dict()/from_dict(). Mirrored to icdev/tools/cortex/. | dataclass construction / dicts | Normalized dataclass instances / JSON-safe dicts |
| Cortex Search Adapters | tools/cortex/search_service.py | Backend adapters normalizing the four native search shapes into CortexSearchResult: search_rag (RAGRetriever, tenant-scoped), search_graph (graph_rag.retrieve, read-only sqlite backend, peak-normalized scores), search_dic (DICSearchEngine, clearance-aware, clearance_required preserved), search_kb (search_knowledge keyword KB). Each adapter is exception-isolated (failure logs + returns []); search_all fans out and merges score-sorted. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx: CortexContext) | list[CortexSearchResult] |
| Cortex Strategy Router | tools/cortex/search_service.py | Agentic routing layer of cortex.search(): classify_route() labels queries (pattern rules for exact_term->kb, relational->graph, document->dic; RAG taxonomy classifier for factual->rag vs ambiguous->parallel fan-out) and search() runs the selected backends via ThreadPoolExecutor with per-backend timeouts from args/cortex_config.yaml (slow backend abandoned, partial results returned). strategy= override (rag/graph/dic/kb/auto/all) bypasses classification; ctx.domain intersects backend selection and records collection scope (ctx-canvas-04 hook). Every result records the decision in .strategy and metadata.router. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx: CortexContext, strategy, config) | list[CortexSearchResult] with routing metadata |
| Cortex Governance Pipeline | tools/cortex/governance.py | The single enforced TRUST chain around every Cortex call: (1) gateway check_text pre-check (block = fail closed, typed GovernanceBlockedError), (2) input redaction (tools/redaction anonymizer), (3) wrapped operation, (4) citation grounding (shared tools/quality/citation_grounding), (5) content grounding cross-check vs injected context, (6) output redaction (tools/llm/output_redactor), (7) provenance record (tools/provenance/registry) + audit row (logger stub until ctx-govern-03). Non-retrieval calls skip only the grounding gates, recorded as "skip" in GovernanceReport. Gate errors fail open (warn) unless CortexContext.fail_closed. @governed decorator form included. Mirrored to icdev/tools/cortex/. | GovernancePipeline.wrap(fn, ctx, prompt=..., context_sources=..., retrieval=...) | (result, GovernanceReport); raises GovernanceBlockedError on block |
| Cortex Analyst | tools/cortex/analyst.py | Unified NL ask-your-data endpoint (`cortex.ask(question, mode, ctx)`), IQE primary + NL→SQL fallback. mode="auto": IQE first (resolve collections → nl_to_iqe → authorize → execute), transparently falling back to the dashboard NLQ pipeline (tools/dashboard/nlq_processor.py) when IQE cannot resolve/translate/authorize (never on execution failures or when canvas=/collections= pinned scope); mode="iqe"/"nlq" pin one engine. Shared pre-execution safety layer on BOTH paths: injection screen on the raw question (deterministic SQL-attack shapes + tools/llm/gateway.py check_text), SELECT-only + single-statement enforcement (nlq_processor.validate_sql), and a table allowlist built from component-registry iqe: collections via get_iqe_mapping() (dotted name + dots→underscores table form). Rejections are audited (nlq_queries status=blocked) and raised as CortexQueryBlocked. Tenant/classification from CortexContext thread into the DB connection via SecurityContext (IQE path). TRUST labeling (ctx-analyst-03): every result carries Citation(source_type="analyst") per collection/table with a row-summary snippet plus metadata confidence labels; raw row answers are grounded by construction (grounding="rows_by_construction"); summarize=True produces LLM prose whose inline [source: ...] tags are validated by the SHARED tools/quality/citation_grounding.py (parse/validate_citations, compute_attribution_score, classify_confidence) — missing/hallucinated tags or an "abstain" attribution band set grounded=False and record a citation_validation gate "fail" (degrade, not refusal). Mirrored to icdev/tools/cortex/. | question, mode ("auto"/"iqe"/"nlq"), CortexContext, canvas/collections/conn/summarize kwargs | CortexResult (text summary, .data rows + executed iqe/sql, analyst citations, .metadata confidence/grounding/citation_report, provider "iqe"/"nlq"), CortexQueryBlocked on safety refusal, CortexAnalystError otherwise |
| Cortex API facade | tools/cortex/api.py | Stable import surface for Cortex consumers: re-exports ask(), CortexAnalystError, CortexQueryBlocked, and all schemas. Later ctx-* epics add search()/complete() alongside. Mirrored to icdev/tools/cortex/. | imports | public Cortex API |
