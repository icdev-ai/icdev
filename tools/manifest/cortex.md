## ICDEV Cortex (Unified AI Facade)
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Cortex Schemas | tools/cortex/schemas.py | Unified normalization contract for the Cortex facade: Citation, CortexSearchResult (score 0-1, backend in {rag,graph,dic,kb}), CortexResult, CortexContext (tenant_id + classification, RLS-ready), GovernanceReport. | Cortex API (complete/classify/extract) | tools/cortex/api.py | First 3 of 7 facade functions over LLMRouter: complete(prompt), classify(text, labels) with deterministic query_classifier degradation when the router raises, extract(text, schema) with output_schema + fenced-JSON parsing. | Cortex Config + Air-Gap Invariant | tools/cortex/config.py | load_cortex_config() reads args/cortex_config.yaml (search strategy_weights/rrf_k/crag_threshold/fan_out_timeouts, governance fail_closed/skip_grounding_for_plain_complete, analyst nlq_fallback_enabled) deep-merged over defaults, mtime-cached; $ICDEV_CORTEX_CONFIG overrides. assert_airgap_ready() verifies every cortex_* routing chain in args/llm_config.yaml keeps a local ollama-tier (no api_key_env) model, raising CortexAirgapError listing missing entries. airgap_exclusions() honors ICDEV_AIRGAP=1 / CortexContext.air_gap by excluding all cloud model_ids so LLMRouter resolves local-only. Mirrored to icdev/tools/cortex/. | optional config path / CortexContext | dict config; None or CortexAirgapError; list of excluded model_ids |
