| Cortex Analyst | tools/cortex/analyst.py | Unified NL ask-your-data endpoint (`cortex.ask(question, mode, ctx)`), IQE primary + NL→SQL fallback. mode="auto": IQE first (resolve collections → nl_to_iqe → authorize → execute), transparently falling back to the dashboard NLQ pipeline (tools/dashboard/nlq_processor.py) when IQE cannot resolve/translate/authorize (never on execution failures or when canvas=/collections= pinned scope); mode="iqe"/"nlq" pin one engine. Shared pre-execution safety layer on BOTH paths: injection screen on the raw question (deterministic SQL-attack shapes + tools/llm/gateway.py check_text), SELECT-only + single-statement enforcement (nlq_processor.validate_sql), and a table allowlist built from component-registry iqe: collections via get_iqe_mapping() (dotted name + dots→underscores table form).
