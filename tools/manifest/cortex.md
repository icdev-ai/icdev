## ICDEV Cortex (Unified AI Facade)
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Cortex Schemas | tools/cortex/schemas.py | Unified normalization contract for the Cortex facade: Citation, CortexSearchResult (score 0-1, backend in {rag,graph,dic,kb}), CortexResult, CortexContext (tenant_id + classification, RLS-ready), GovernanceReport. All dataclasses round-trip via to_dict()/from_dict(). Mirrored to icdev/tools/cortex/. | dataclass construction / dicts | Normalized dataclass instances / JSON-safe dicts |
| Cortex Search Adapters | tools/cortex/search_service.py | Backend adapters normalizing the four native search shapes into CortexSearchResult: search_rag (RAGRetriever, tenant-scoped), search_graph (graph_rag.retrieve, read-only sqlite backend, peak-normalized scores), search_dic (DICSearchEngine, clearance-aware, clearance_required preserved), search_kb (search_knowledge keyword KB). Each adapter is exception-isolated (failure logs + returns []); search_all fans out and merges score-sorted. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx: CortexContext) | list[CortexSearchResult] |
| Cortex Strategy Router | tools/cortex/search_service.py | Agentic routing layer of cortex.search(): classify_route() labels queries (pattern rules for exact_term->kb, relational->graph, document->dic; RAG taxonomy classifier for factual->rag vs ambiguous->parallel fan-out) and search() runs the selected backends via ThreadPoolExecutor with per-backend timeouts from args/cortex_config.yaml (slow backend abandoned, partial results returned). strategy= override (rag/graph/dic/kb/auto/all) bypasses classification; ctx.domain intersects backend selection and records collection scope (ctx-canvas-04 hook). Every result records the decision in .strategy and metadata.router. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx: CortexContext, strategy, config) | list[CortexSearchResult] with routing metadata |
