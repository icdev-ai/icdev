## ICDEV Cortex (Unified AI Facade)
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Cortex Schemas | tools/cortex/schemas.py | Unified normalization contract for the Cortex facade: Citation, CortexSearchResult (score 0-1, backend in {rag,graph,dic,kb}), CortexResult, CortexContext (tenant_id + classification, RLS-ready), GovernanceReport. All dataclasses round-trip via to_dict()/from_dict(). Mirrored to icdev/tools/cortex/. | dataclass construction / dicts | Normalized dataclass instances / JSON-safe dicts |
| Cortex API (complete/classify/extract) | tools/cortex/api.py | First 3 of 7 facade functions over LLMRouter: complete(prompt), classify(text, labels) with deterministic query_classifier degradation when the router raises, extract(text, schema) with output_schema + fenced-JSON parsing. Routing via cortex_complete/cortex_classify/cortex_extract entries in args/llm_config.yaml — no model IDs in code. CortexContext tenant_id/classification threaded into LLMRequest. Calls assert_airgap_ready() at import time. Mirrored to icdev/tools/cortex/. | prompt/text + optional CortexContext | CortexResult with provider/model/cost/latency_ms accounting |
| Cortex Config + Air-Gap Invariant | tools/cortex/config.py | load_cortex_config() reads args/cortex_config.yaml (search strategy_weights/rrf_k/crag_threshold/timeouts, governance fail_closed/skip_grounding_for_plain_complete, analyst nlq_fallback_enabled) deep-merged over defaults, mtime-cached; $ICDEV_CORTEX_CONFIG overrides. assert_airgap_ready() verifies every cortex_* routing chain in args/llm_config.yaml keeps a local ollama-tier (no api_key_env) model, raising CortexAirgapError listing missing entries. airgap_exclusions() honors ICDEV_AIRGAP=1 / CortexContext.air_gap by excluding all cloud model_ids so LLMRouter resolves local-only. Mirrored to icdev/tools/cortex/. | optional config path / CortexContext | dict config; None or CortexAirgapError; list of excluded model_ids |
| Cortex Search Adapters | tools/cortex/search_service.py | Backend adapters normalizing the four native search shapes into CortexSearchResult: search_rag (RAGRetriever, tenant-scoped), search_graph (graph_rag.retrieve, read-only sqlite backend, peak-normalized scores), search_dic (DICSearchEngine, clearance-aware, clearance_required preserved), search_kb (search_knowledge keyword KB). Each adapter is exception-isolated (failure logs + returns []); search_all fans out and merges score-sorted. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx: CortexContext) | list[CortexSearchResult] |
| Cortex Strategy Router | tools/cortex/search_service.py | Agentic routing layer of cortex.search(): classify_route() labels queries (pattern rules for exact_term->kb, relational->graph, document->dic; RAG taxonomy classifier for factual->rag vs ambiguous->parallel fan-out) and search() runs the selected backends via ThreadPoolExecutor with per-backend timeouts from args/cortex_config.yaml (slow backend abandoned, partial results returned). strategy= override (rag/graph/dic/kb/auto/all) bypasses classification; ctx.domain intersects backend selection and records collection scope (ctx-canvas-04 hook). Every result records the decision in .strategy and metadata.router. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx: CortexContext, strategy, config) | list[CortexSearchResult] with routing metadata |
| Cortex CRAG Corrective Loop | tools/cortex/search_service.py | Corrective retrieval pass of cortex.search() (ctx-search-04): when the fused top score falls below search.crag_threshold (args/cortex_config.yaml), rewrite_query() rewrites the query via the cortex_search_rewrite routing chain (local ollama fallback per ctx-core-03, air-gap forced local via api._invoke) and routing+fusion re-runs exactly once; both passes merge deduped by (backend, source_id, content) with best score winning. Results carry metadata.corrective_pass=True + a crag record (threshold, original/rewritten query, original top score); an unavailable or unchanged rewrite returns the originals with metadata.corrective_skipped=<reason>. Missing/zero threshold disables the loop. Mirrored to icdev/tools/cortex/. | (query, top_k, ctx, strategy, config) via search() | list[CortexSearchResult] with corrective metadata |
| Cortex Governance Pipeline | tools/cortex/governance.py | The single enforced TRUST chain around every Cortex call: (1) gateway check_text pre-check (block = fail closed, typed GovernanceBlockedError), (2) input redaction (tools/redaction anonymizer), (3) wrapped operation, (4) citation grounding (shared tools/quality/citation_grounding), (5) content grounding cross-check vs injected context, (6) output redaction (tools/llm/output_redactor), (7) provenance record (tools/provenance/registry) + one append-only cortex_audit row (ctx-govern-03) written through the RLS-aware storage shim, plus a structured logger line. Non-retrieval calls skip only the grounding gates, recorded as "skip" in GovernanceReport. Gate errors fail open (warn) unless CortexContext.fail_closed. @governed decorator form included. Mirrored to icdev/tools/cortex/. | GovernancePipeline.wrap(fn, ctx, prompt=..., context_sources=..., retrieval=...) | (result, GovernanceReport); raises GovernanceBlockedError on block |
| Cortex Session + Audit Persistence | tools/cortex/db/init_db.py | Persists the two governance tables (migration 259): cortex_sessions (mutable per-caller session lifecycle) and cortex_audit (one append-only row per governed call, NIST AU — in APPEND_ONLY_TABLES). SCHEMA_PG is canonical DDL; SCHEMA_SQLITE derived via .replace() so backends never drift. Uses the RLS-aware get_connection() (NOT get_canvas_connection) because both tables carry tenant_id+classification — reads are row-level filtered by tenant + Bell-LaPadula read-down. record_audit() / ensure_session() author %s placeholders and pass Python bool for PG BOOLEAN columns (int 1/0 fails on PG). Wired to GovernancePipeline gate 7b. Mirrored to icdev/tools/cortex/db/. | record_audit(payload) / ensure_session(ctx) / init_db(conn=None) | audit row id / session id / None |
| Cortex PG Acceptance Check | tools/cortex/db/verify_pg.py | Live-PostgreSQL acceptance gate for the audit/session tables (the unit suite runs on the SQLite fallback; PG is the primary target). Applies the schema, writes append-only rows for two distinct tenants, and asserts each tenant's RLS SecurityContext sees only its own rows, plus blocked-outcome derivation. Per-run uuid tenant suffix so repeated runs never collide on append-only rows. Run from repo root: `python tools/cortex/db/verify_pg.py --json`; exit code + "ok" gate PR/CI. | --json | {ok, backend, checks[]} |
