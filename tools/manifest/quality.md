| Divergence Critic (Focus half) | tools/quality/divergence_critic.py | dvg-critic-01/02 scorer for the raw idea pool from `invoke_divergence`. SEPARATE opposing LLM call (harsh-critic system prompt, never a continuation of the generator); LLM emits categorical enums per idea on novelty/viability/fit + rationale AND a **trap** flag (seductive-but-broken) with a MANDATORY why; Python composes composite + ordering via `compose_divergence` and the trap verdict via `compose_trap` (unexplained trap flag demoted to non-actionable). | Constitutional AI (per-rule critique/revise) | tools/quality/constitutional_ai.py | agx-verify-02 per-rule critique + targeted revision for LLM-drafted artifacts. | Component Scorer (dimension extractors) | tools/quality/component_scorer.py | idp-score-01 dimension extractors over ICDEV's OWN measurement subsystems — the complement to `tools/idp/scorecard.py` (which grades against declared YAML/IQE rules). Four extractors, one per source: `extract_health` (newest `awareness_component_health` HTTP probe per route via the IDP IQE adapter, falling back to `canvas_health/health_data.py` green/amber/red), `extract_compliance` (`canvas_compliance/posture.py::compute_canvas_posture`, joined on the **module package** because posture rows are named "Network" while the registry key is `ndc`), `extract_coherence` (a supplied `CoherenceReport`; never fetched implicitly — a sweep is minutes long), `extract_completeness` (the 8-point canvas gate). Each returns a `DimensionScore(score, evidence_count, status)` where `status` is `ASSESSED` or the `NOT_ASSESSED` sentinel. **Unassessed is never 0:** `DimensionScore.measured()` downgrades itself when `evidence_count <= 0`, a posture row scoring 0 with no findings is reported unassessed (an empty assessment table, not a failure), a non-canvas completeness report is unassessed (not 0%), and a component no coherence check names is unassessed (not 100%). Extractors never raise; a missing table or module costs a dimension its score, not the caller its run. Every extractor accepts its source injected for testing. Known upstream limitation surfaced (not hidden) as `detail.findings_backed`: subtraction-style canvases score a vacuous `100.0` over an empty table. **Aggregation + persistence (idp-score-01-d3):** `aggregate_score(dimensions, weights=None)` folds the four dimensions into a weighted `overall_score` (0-100) and an A-F `letter_grade` banded off `tools/idp/scorecard.py::DEFAULT_GRADE_BANDS`. **The honesty rule:** ANY `NOT_ASSESSED` dimension caps `overall_score` at `None` and `letter_grade` at `None` — renormalizing the weights over a subset would silently redefine what the number means, and the dimensions most often unassessed are the ones that would have lowered it. Default weights are deliberately UNIFORM (nothing has measured their relative predictive value); caller weights are normalized, so unnormalized input is fine. `persist_scorecard(result, conn)` upserts one row per component into `developer_scorecards` keyed on `component_id` (the component grain from migration `20260802145147`), writing `overall_score`/`letter_grade` as NULL for an unassessed component rather than 0/'F'. `compliance_score` is the ONLY legacy dimension column populated — it is the one genuine semantic match; the other four stay NULL rather than hold a lookalike number. Full breakdown incl. per-source evidence counts lands in `dimension_details` JSON. Raises `ScorecardPersistError` (never swallows) when the live schema predates the component-grain migration. `persist_all()` sweeps the registry under one shared `evaluated_at`; a component that raises is reported in `errors`, not fatal. | `<component-key> \| --all \| --json \| --persist`; library `extract_*`, `score_component`, `aggregate_score`, `letter_grade`, `persist_scorecard`, `persist_all`, `registry_component_keys`, `resolve_component`, `EXTRACTORS`, `DIMENSIONS`, `DEFAULT_WEIGHTS`, `INSERT_COLUMNS` | `DimensionScore` per dimension; `score_component` adds `overall` (mean of ASSESSED dimensions only) and `aggregate` (the publishable verdict: `overall_score`, `letter_grade`, `dimension_details`) |
| Component Scoring Sweep (runner) | tools/quality/run_component_scoring.py | idp-score-01-d4 operational entry point for the scorer above: loads every component in `args/component_registry.yaml` and upserts each verdict into `developer_scorecards` via `component_scorer.persist_scorecard`. **`--dry-run` is genuinely dry** — the persist call is never made, so the sweep runs in CI against an unmigrated database and leaves nothing behind; this is the shape the `Component scoring sweep (dry run)` step in `.github/workflows/icdev-ci.yml` runs. Fetches `compute_canvas_posture` and `get_canvas_health` ONCE for the whole sweep and injects them (`score_component` otherwise re-fetches the whole platform per component — 68 full posture computations). A source that RAISES is reported and deliberately not injected, so the extractor produces its own accurate reason rather than the misleading 'returned no rows' an empty list would yield. Reports `unassessed_by_dimension`, the actionable half of an all-unassessed sweep: it names which measurement subsystem is dark. **Exit codes are load-bearing:** `0` swept to completion (components MAY be unassessed — NOT_ASSESSED is a finding about coverage, not a failed run, and reddening CI over it would earn a `|| true`), `1` at least one component raised while being scored or persisted (the rest still completed), `2` the sweep could not start (registry unloadable, or persistence asked for with no connection). Without `--coherence-report` the coherence dimension is NOT_ASSESSED for every component, which by the honesty rule caps every overall score at NULL — `extract_coherence` refuses to trigger a minutes-long sweep as a side effect of scoring. | `--dry-run \| --json \| --keys k1,k2 \| --coherence-report PATH`; library `run_scoring`, `prefetch_sources`, `load_coherence_report`, `render` | Run report: `scored`, `assessed`, `unassessed`, `unassessed_by_dimension`, `sources`, `components[]`, `persisted[]`, `errors[]` |
| Review Loop | tools/quality/review_loop.py | Local "review-until-green" loop (greploop-adapted): runs ICDEV's own gates (ruff lint, coherence_checker, SIPA integrity) over the local diff as a score function, applies deterministic autofixes, and iterates until every blocking gate passes or max_iterations. Pre-PR analog of tools/ci/pr_watcher.py; emits a fix_brief of remaining findings for the driving agent. Config: args/review_loop_config.yaml | --base \<ref\>, --max N, --no-autofix, --no-audit, --json, --gate | Per-iteration score table + fix_brief; --gate exits 0=green/1=not |
