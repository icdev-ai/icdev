## Quality Gates
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Rigor Gates | tools/quality/rigor_gates.py | IL-tier quality rigor gates: coverage and static-analysis thresholds; auto-discovers coverage.xml; graceful degrade if no coverage data available | --tier (il2/il4/il5/il6), --project-dir, --coverage, --json, --gate | Gate pass/fail with violations list |
| Completion Auditor | tools/quality/completion_auditor.py | Per-canvas 8-component completeness scorecard; enumerates EVERY dashboard canvas (not just those with page.html) and scores each against the CLAUDE.md completeness gate — surfaces canvases the coherence gate never sees | --json, --md | JSON to stdout, or writes docs/quality/completion-scorecard.md (sorted least→most complete) |
| Categorical Scoring (deterministic-picker) | tools/quality/categorical_scoring.py | agx-pick-02 composition half of the deterministic-picker rule: the LLM emits only a 3-value enum per dimension, pure Python composes the score/verdict. Versioned vocabularies + `compose_fitness` / `compose_eval_overall` / `compose_grounding` / `compose_divergence`; unknown tokens degrade deterministically (neutral for fitness/eval/divergence, fail-closed for grounding). Consumed by fitness.py, ace/evaluator.py, content_grounding.py, divergence_critic.py | (library) VOCABULARY_VERSION, compose_* fns | Composed float in [0,1] + vocabulary_version provenance |
| Divergence Critic (Focus half) | tools/quality/divergence_critic.py | dvg-critic-01/02 scorer for the raw idea pool from `invoke_divergence`. SEPARATE opposing LLM call (harsh-critic system prompt, never a continuation of the generator); LLM emits categorical enums per idea on novelty/viability/fit + rationale AND a **trap** flag (seductive-but-broken) with a MANDATORY why; Python composes composite + ordering via `compose_divergence` and the trap verdict via `compose_trap` (unexplained trap flag demoted to non-actionable). Unlike gap_scorer.py (scores against a DB of known items), scores ideas with no DB row yet. `ScoredPool.trap_warnings()` yields ADVISORY (never 'block') warnings for the creative/innovation triage decision point. `cluster_pool()` groups the scored pool by underlying approach (critic-assigned `cluster_label`, frame fallback) so restatements collapse; `cluster_and_deepen(pool, *, function, router, k)` expands only the top-K clusters (K config-driven `divergence.deepen_top_k`, default 3) into actionable sketches (risks + next steps) via a SEPARATE call — structured output for dvg-wire-* (dvg-critic-03). Degrades cleanly (empty_pool / critic_unavailable / unparseable_critic_output; deepening best-effort). Persists to `divergence_idea_scores` (migrations 293/294) keyed by trace_id | `score_idea_pool(pool_text, *, function, trace_id=..., router=..., persist=True)` / CLI `--function --pool-file [--json]` | `ScoredPool(ordered=[IdeaScore...])` + `.trap_warnings()` + `cluster_and_deepen()` |
| Constitutional AI (per-rule critique/revise) | tools/quality/constitutional_ai.py | agx-verify-02 per-rule critique + targeted revision for LLM-drafted artifacts. Rules loaded as DATA from `args/security_gates.yaml` `constitution:` block (single-source encoding of existing gate/CUI/TRUST invariants). Each rule critiqued in its OWN call → 3-value enum verdict `{pass/fail/not_applicable}` + offending span; Python composes overall via **any-block-rule-fail** policy; failed BLOCK rules get a bounded targeted revision (no silent give-up). Per-rule trail → append-only `constitutional_audit_log` (migration 292). Fail-closed on malformed | `constitutional_review(artifact, artifact_type=..., router=...)` | {passed, revised_text, rule_trace[], failed/unresolved rules, audit_records} |
| Component Scorer (dimension extractors) | tools/quality/component_scorer.py | idp-score-01 dimension extractors over ICDEV's OWN measurement subsystems — the complement to `tools/idp/scorecard.py` (which grades against declared YAML/IQE rules). Four extractors, one per source: `extract_health` (newest `awareness_component_health` HTTP probe per route via the IDP IQE adapter, falling back to `canvas_health/health_data.py` green/amber/red), `extract_compliance` (`canvas_compliance/posture.py::compute_canvas_posture`, joined on the **module package** because posture rows are named "Network" while the registry key is `ndc`), `extract_coherence` (a supplied `CoherenceReport`; never fetched implicitly — a sweep is minutes long), `extract_completeness` (the 8-point canvas gate). Each returns a `DimensionScore(score, evidence_count, status)` where `status` is `ASSESSED` or the `NOT_ASSESSED` sentinel. **Unassessed is never 0:** `DimensionScore.measured()` downgrades itself when `evidence_count <= 0`, a posture row scoring 0 with no findings is reported unassessed (an empty assessment table, not a failure), a non-canvas completeness report is unassessed (not 0%), and a component no coherence check names is unassessed (not 100%). Extractors never raise; a missing table or module costs a dimension its score, not the caller its run. Every extractor accepts its source injected for testing. Known upstream limitation surfaced (not hidden) as `detail.findings_backed`: subtraction-style canvases score a vacuous `100.0` over an empty table. | `<component-key> \| --all \| --json`; library `extract_*`, `score_component`, `resolve_component`, `EXTRACTORS`, `DIMENSIONS` | `DimensionScore` per dimension; `score_component` adds `overall` (mean of ASSESSED dimensions only, `None` when nothing assessed) |
| Review Loop | tools/quality/review_loop.py | Local "review-until-green" loop (greploop-adapted): runs ICDEV's own gates (ruff lint, coherence_checker, SIPA integrity) over the local diff as a score function, applies deterministic autofixes, and iterates until every blocking gate passes or max_iterations. Pre-PR analog of tools/ci/pr_watcher.py; emits a fix_brief of remaining findings for the driving agent. Config: args/review_loop_config.yaml | --base \<ref\>, --max N, --no-autofix, --no-audit, --json, --gate | Per-iteration score table + fix_brief; --gate exits 0=green/1=not |

| IL4     | 80%         | Yes           | Yes           | Yes           |
| IL5     | 85%         | Yes           | Yes           | Yes           |
| IL6     | 90%         | Yes           | Yes           | Yes           |
