| Component Scorer (dimension extractors) | tools/quality/component_scorer.py | idp-score-01 dimension extractors over ICDEV's OWN measurement subsystems — the complement to `tools/idp/scorecard.py` (which grades against declared YAML/IQE rules). | Structured Output Contract | tools/quality/structured_output.py | trust-struct-01 — the ONE contract validator for LLM output. Deliberately NOT `jsonschema`: the optional-import pattern in `tools/cortex/api.py::_validate_against_schema` returns `(True, "")` when the package is absent, i.e. an air-gapped deployment validates nothing and reports that everything conformed. Array length is never repaired: how many items there should be is caller knowledge (`content_grounding` pads to the claim count IT segmented). `repair_once` is bounded to ONE retry by construction, not by a loop counter a later edit can raise.
