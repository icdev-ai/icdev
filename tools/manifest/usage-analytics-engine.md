# Usage Analytics Engine

> Shard of `tools/manifest.md`. See index at `tools/manifest.md`.

## Usage Analytics Engine
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Event Collector | tools/usage_analytics/event_collector.py | Flask middleware that auto-records all dashboard HTTP requests to `usage_events`; excludes configured routes/IPs; hashes IPs with SHA256 for privacy. No CLI — imported as a library. Middleware hook: `track_request(app)` registers `before_request`/`after_request` hooks that capture route, method, status_code, duration_ms, and feature_tag (first URL segment). DB table: `usage_events` (id, route, method, status_code, duration_ms, skill_invoked, user_session, ip_hash, feature_tag, occurred_at). Config: `args/usage_analytics_config.yaml` `collection.exclude_routes`, `collection.exclude_ips`. | Library import only: `from tools.usage_analytics.event_collector import track_request; track_request(app)` | Event ID string on success; empty string if excluded or error |
| Analytics Engine | tools/usage_analytics/analytics_engine.py | Aggregates raw `usage_events` into `usage_aggregates` per feature_tag × date; scores feature adoption with 3-day vs 7-day trend (rising/flat/declining); cross-registers low-adoption or high-error features as `innovation_signals` with day-scoped SHA256 dedup. Config: `args/usage_analytics_config.yaml` `scoring.low_adoption_threshold` (default 0.05), `scoring.high_error_threshold` (default 0.10), `aggregation.rollup_interval_hours` (default 24). DB tables read: `usage_events`, `usage_aggregates`. DB tables written: `usage_aggregates`, `innovation_signals`. | --aggregate (roll up events), --days N (lookback window, default 1), --score (print adoption scores), --surface-signals (register flagged features to innovation_signals), --report (full adoption report), --daemon (continuous loop on rollup_interval_hours), --json | Aggregated row count / FeatureAdoptionResult list / signals inserted count; JSON when --json |
