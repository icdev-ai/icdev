| LLM Proxy Gateway | tools/llm/proxy_gateway.py | Opt-in (off by default) application-layer redirect of a CLOUD provider's `base_url` to the shared LLM proxy + swap of its `api_key_env` for a VIRTUAL key, so the real provider key never leaves the proxy (lpx-proxy-03/keys-04). Only `anthropic`/`openai`/`gemini`/`azure_openai` are ever redirected; `ollama` (local) and `bedrock` (GovCloud/CUI) are never touched, preserving air-gap/CUI paths. CUI egress gate (lpx-egress-02): `proxy_egress_classification_block()` refuses CUI+ over the proxy (fail-closed, invoke-time; ceiling via `ICDEV_LLM_PROXY_MAX_CLASSIFICATION`, default UNCLASSIFIED). | LLM Proxy Keys | tools/llm/proxy_keys.py | Issue/list/show/revoke/rotate/expire/audit LLM-proxy virtual keys for /gameday & /academy cohorts (lpx-keys-01/03). Key returned exactly once at creation; only a SHA-256 hash is stored (mirrors api_key_auth). Master/admin key read from `ICDEV_LLM_PROXY_MASTER_KEY`, never logged or returned. Best-effort LiteLLM `/key/generate` sync when the proxy is enabled+reachable, OFF by default. Scopes onto existing tenancy: tenant/team/guild/user. Rotation/revocation are per-key + immediate; default expiry via `ICDEV_LLM_PROXY_KEY_TTL_DAYS` (default 30, 0 disables); every lifecycle event appends to the APPEND-ONLY `llm_proxy_key_audit` (NIST AU). MCP tools: `proxy_key_issue`/`proxy_key_list`/`proxy_key_show` | issue/list/show/revoke/rotate/expire/audit subcommands + --json | key metadata (+ virtual_key once on issue/rotate) |
| LLM Proxy Team Budgets | tools/llm/proxy_team_budgets.py | Gameday-facing per-team spend budgets (lpx-teams-02). A team's budget IS its exercise-scoped virtual key's budget (reuses lpx-keys-02 engine + tables — no parallel table). provision/check/status/record with a facilitator_message on exhaustion (clear reason, not a 500). Per-EXERCISE window (resets per session), NOT per-month. Academy decided separately (per-guild, month). Attribution is per-TEAM not per-member (join-by-code limit, documented). `provision`/`check`/`status` subcommands | session_id team_id [--budget/--projected] | allow/warn/block + per-team status |
| LLM Proxy Team Limits | tools/llm/proxy_team_limits.py | Per-team RPM/TPM rate ceilings for /gameday competition fairness (lpx-teams-01). Keyed on ttx_teams.team_id scoped to the active ttx_sessions.session_id; exceeding a team's ceiling degrades ONLY that team. Ceilings sized off ACTUAL team count (COUNT ttx_teams, fallback max_teams) x org_limit/N x burst_factor — configurable per session, never hardcoded. Minute-bucket windows; facilitator status with at_ceiling flag. Orthogonal to gateway cost cap, rate_gate concurrency, and proxy_budgets dollars. `configure`/`check`/`status` subcommands | session_id [team_id] [--tokens] | allow/deny + per-team status |
| LLM Proxy Budgets | tools/llm/proxy_budgets.py | Per-key spend budget accounting + allow/warn/block enforcement (lpx-keys-02). Wires budgets onto existing grouping units via the key's scope (team/guild/user); deny is scoped to a single key/window so one team exhausting its budget never blocks another. Windowed (exercise/day/month/none). Additional layer to gateway.py's per-agent cost cap; orthogonal to rate_gate.py concurrency gate. `check`/`spend`/`record` subcommands | key_id + --projected/--cost | allow\|warn\|block decision / spend summary |
| LLM Proxy Metrics | tools/llm/proxy_metrics.py | Scrape proxy spend + rate metrics into ICDEV observability (lpx-obs-01), surfaced on the Ops Hub LLMOps page (/ops/llm). Never raises; absent proxy → available:false (air-gap safe). Not joined with the ledger — reconciliation is proxy_reconcile.py. | `--window-hours N` `--top N` `--no-scrape` `--json` | unified metrics dict |
| LLM Proxy Reconcile | tools/llm/proxy_reconcile.py | Reconcile proxy spend vs token_tracker + gateway audit (lpx-obs-02). Compares `llm_proxy_spend` against `agent_token_usage` over a window by windowed AGGREGATION (NOT a row join — keyed differently: proxy=key/scope, tracker=agent); `llm_gateway_audit` corroborates request volume (no cost column). Structural gaps explained not hidden (tracker superset, cache hits, differing keys). `--gate` (exit 1) fires only when the proxy is active AND both sides have spend AND divergence > threshold (default 10%); inactive proxy → `proxy_inactive`, never a false alarm. PG-portable. | `--window-hours N` `--threshold-pct P` `--gate` `--json` | reconciliation report (reconciled\|divergent\|proxy_inactive) |
