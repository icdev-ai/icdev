| Gateway Event Dispatch | tools/studio/event_dispatch.py | The last hop from gateway to workflow engine (dwo-evt-02). Registers NO route — called from inside the existing handler in `gateway_agent._register_webhook_route`, *after* the allowlist check and *after* `run_security_chain` passes, so an event failing any of the eight gates starts nothing. Enforces three properties: idempotency (`source:delivery:trigger` claimed in a UNIQUE audit column before the run starts, so a replayed webhook starts exactly one run), classification (a run inherits the more conservative of the channel and source ceilings; a trigger targeting a workflow below that IL is refused and audited, never downgraded), and asynchrony (a daemon thread — the webhook response never waits on a workflow). Functions: `dispatch_envelope(envelope, channel_config, payload, headers)`, `dispatch_envelope_async(...)`, `extract_delivery_id()`, `event_classification()`. | CommandEnvelope + channel config + payload + headers | `{"matched": n, "started": [...], "refused": [...], "classification": IL, "deduplicated": bool}` |
