| Run Resume | tools/studio/workflow_runner.py + tools/dashboard/api/studio.py | Continues a run left mid-flight (dwo-dur-01/02/03). `resume_run(run_id)` re-attaches a worker to the ORIGINAL run row — `RESUME_MODE == "in_place"`, it does NOT fork a run linked by `resumed_from_run_id`, because a gate parked at `awaiting_approval` keeps its `step_run_id` and that step row is keyed to the original `run_id` (forking would strand every approval issued before the interruption).
