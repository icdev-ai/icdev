| Experiment Reflex honesty (xrv-lab-01) | tools/genesis/reflexes/experiment.py | Three verdicts and two of them report NO number: `disabled` (the switch is off — the loop is not run and no counts are reported), `unmeasurable` (any domain's `run_loop` result carried `placeholder_metrics: True`, or no domain measured, or 0 experiments ran) and `ok`. `run_loop` evaluates the domain, creates an experiment, runs it and evaluates AGAIN with nothing changed, so every result it returns today is placeholder; the reflex published an `acceptance_rate` off those deltas nightly. | Real Mutation (xrv-lab-02) | tools/autoresearch/real_mutation.py | ONE domain (`code_quality`) measures something real: a worktree on `autoresearch/<candidate>` under the declared `git.worktree_base`, fitness measured BEFORE on the base and AFTER on the claude_cli-patched tree by the SAME evaluator, then `experiment_engine.decide` (unchanged) on two real numbers. `REAL_MUTATION_DOMAINS` is a Python tuple and `real_mutation.domains` can only NARROW it. Gated by `real_mutation.enabled` (DEFAULT FALSE) + `ICDEV_AUTORESEARCH_REAL_MUTATION`; fail-closed on an unreadable switch. A failed evaluation is `metric: None`, NEVER 0.0. `unmeasurable` is its own outcome and never folds into `discarded`. The decision is fed the SCOPED pair (the directory the patch touched, its BEFORE reconstructed read-only from HEAD) because the tree-wide average over ~1,700 files cannot detect a one-file change -- measured 2026-09-12, 0.9312 -> 0.9312 for a patch that moved its own directory 0.988 -> 0.824; an unscopeable patch falls back with the dilution NAMED (`decision_basis: tree_wide_diluted`) and both pairs ride on every result. Keep = commit, push, `gh pr create`; there is NO merge verb, AST-pinned. Discard = `git worktree remove` (forced only after PROVING the tree holds no commit beyond its base) + `git branch -d`. Cost rides xrv-cost-02's `record_task_cost` with task_id = the candidate id. | `python -m tools.autoresearch.real_mutation` --gate, --lanes, --plan, --domain, --json | Gate verdict / lane census / plan; `run_real_experiment()` returns one of kept\|discarded\|unmeasurable\|refused |
