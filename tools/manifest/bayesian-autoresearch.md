The ENV OVERRIDE OUTRANKS THE CONFIG in both directions (it is the per-host knob for an opt-in loop that ships off); an unreadable config is FAIL-CLOSED and reported as `basis: config_unreadable`, with `config_enabled: None` so "declared off" and "could not tell" stay apart. | import — `autoresearch_enabled(env=None)` | `{enabled, basis, env_var, env_value, config_enabled}` |
| Experiment Reflex honesty (xrv-lab-01) | tools/genesis/reflexes/experiment.py | Three verdicts and two of them report NO number: `disabled` (the switch is off — the loop is not run and no counts are reported), `unmeasurable` (any domain's `run_loop` result carried `placeholder_metrics: True`, or no domain measured, or 0 experiments ran) and `ok`. `run_loop` evaluates the domain, creates an experiment, runs it and evaluates AGAIN with nothing changed, so every result it returns today is placeholder; the reflex published an `acceptance_rate` off those deltas nightly. Unmeasurable now means `metric_value` None, `total_kept`/`total_discarded`/`acceptance_rate` None, and NO GKP export, with the engine's own `placeholder_note` carried through. A placeholder domain's keep count rides as `kept_unmeasured`, never `kept`. `_rate` is the one place a rate is computed and is None over an empty denominator. | config dict, trust kernel | Reflex result; GKP only from a measured run |
