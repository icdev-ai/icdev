## AI-ify Canvas (AI-ify)

Scans source repositories for AI-augmentable code patterns and produces a scored, phase-banded modernization roadmap. Primary path: Semgrep CLI (multi-language, 8 pattern rules). Air-gap fallback: Python `ast` walker for `.py` and a regex/tree-sitter path for `.cs`. Scores each opportunity using a deterministic weighted multi-criteria model (`args/aiify_config.yaml`). Persists results to PostgreSQL (default) or SQLite (`data/aiify_canvas.db`). Integrates with AIMC (`/ai-ml/models/new`) and AADC (`/agentic-ai/topologies/new`) for downstream tooling. Feature flag: `ICDEV_AIIFY_ENABLED`. IQE collections: `aiify.opportunities`, `.scans`, `.roadmaps`. Classification: CUI // SP-CTI.

| AI-ify Pipeline Engine | tools/aiify/engine.py | Full 7-step pipeline orchestrator. (1) `init_db()`, (2) `run_readiness_check()`, (3) INSERT `aiify_scans` status=running, (4) `detect_patterns()`, (5) INSERT `aiify_opportunities` + `score_opportunity()` per hit, (6) INSERT `aiify_scores`, (7) `generate_roadmap()`, (8) UPDATE `aiify_scans` status=completed + audit log. Maps each `pattern_type` to an `ai_paradigm` and a recommended IL model. | `run_scan(input_type, input_ref, scan_context=None) -> dict` | `{scan_id, opportunities_count, scores_count, roadmap_id, status, pillar_scores, overall_readiness_score, icdev_checks}` |
| Pattern Classifier | tools/aiify/pattern_classifier.py | Semgrep CLI wrapper + Python AST fallback + C# regex/tree-sitter fallback. Detects 8 pattern types: `nested_conditionals` (if-depth ≥ 3), `regex_user_input`, `string_template_rendering`, `scheduled_cron`, `hardcoded_threshold`, `db_render_notify_chain`, `keyword_list_search`, `large_rule_table`. Config: `args/aiify_config.yaml` (pattern_min_depth, rule_min_keys, semgrep.rules_dir, semgrep.timeout_seconds). | `detect_patterns(target_path: str) -> list[dict]` | List of `{pattern_type, module_path, function_name, line_start, line_end, language, pattern_detail}` |
| Opportunity Scorer | tools/aiify/opportunity_scorer.py | Deterministic weighted multi-criteria scorer. Sub-scores: `value = usage_freq*0.40 + task_complexity*0.35 + automation_deficit*0.25`; `feasibility = data_avail*0.40 + il_model_exists*0.35 + (1-integration_complexity)*0.25`; `risk = reversibility*0.40 + compliance_impact_inv*0.35 + (1-dep_complexity)*0.25`; `composite = value*0.45 + feasibility*0.35 + (1-risk)*0.20`. IL-level penalty applied to compliance when `il_level=il5/il6`. Weights hot-reloaded from `args/aiify_config.yaml`; degrades to built-in defaults on missing file. CLI: `--opportunity-file PATH` or individual `--usage-freq / --task-complexity / ...` flags. | `score_opportunity(opportunity: dict, scan_context: dict) -> dict` · CLI: `python tools/aiify/opportunity_scorer.py [--opportunity-file PATH] [--json]` | `{value_score, feasibility_score, risk_score, composite_score, score_detail}` all in [0.0, 1.0] |
| Roadmap Generator | tools/aiify/roadmap_generator.py | Builds a prioritized roadmap from scored opportunities. Phase bands: P1 ≥ 0.7 (Quick Wins), P2 ≥ 0.5 (Core Modernization), P3 ≥ 0.3 (Long-Horizon Investments). Effort days from `context/aiify/pattern_catalog.json` midpoints. Emits `aimc_links` and `aadc_links` (agentic_trigger paradigm only). Persists to `aiify_roadmaps` via `get_connection()`. | `generate_roadmap(scan_id, opportunities: list[dict], scores: list[dict]) -> dict` | `{roadmap_id, scan_id, title, phases, aimc_links, aadc_links, total_effort_days, created_at}` |
| DB Initializer | tools/aiify/db/init_db.py | Dual-backend schema bootstrap. Backend priority: `AIIFY_STORAGE_BACKEND` → `ICDEV_CANVAS_STORAGE_BACKEND` → PostgreSQL default; SQLite fallback to `data/aiify_canvas.db` (`AIIFY_DB_PATH` override). Tables: `aiify_scans`, `aiify_opportunities`, `aiify_scores`, `aiify_roadmaps`, `aiify_audit_log`. CHECK constraints derived from `constants.PATTERN_TYPES`, `constants.AI_PARADIGMS`, `constants.SUPPORTED_LANGUAGES` — never hardcoded. All SQL constraints must be derived from these constants. | (library) | `PATTERN_TYPES, AI_PARADIGMS, SUPPORTED_LANGUAGES, IL_LEVELS, SCORING_WEIGHTS, CHECK_PATTERN_TYPE, CHECK_AI_PARADIGM` |

Runs 11 pillars in weighted order: code_quality (1.0), documentation (1.0), testing (1.2), structure (0.8), dependencies (1.0), configuration (1.0), security (1.0), il_classification (ICDEV, 1.0), nist_controls (ICDEV, 1.0), stig_compliance (ICDEV, 1.0), append_only_audit (ICDEV, 1.0). Enables natural-language queries against AI-ify data via the IQE engine at `POST /api/iqe-query`. | (auto-registered on import) | IQE collections: opportunities, scans, roadmaps |
