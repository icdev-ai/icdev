# Twin Core — Cross-Canvas Digital-Twin Unification (TWX)

> Shard of `tools/manifest.md`. See index at `tools/manifest.md`.
>
> `tools/twin_core/` is an **additive** layer that unifies the eight working canvas digital twins (NDC, PDC, BDC, SDC, DDC, ODC, IDC, Mission) behind one registry and one canonical verdict/violation schema — **without rewriting any of them**. Adapters translate each canvas's native twin output into the canonical schema, preserving `method`/provenance. Sequoia-Combine Pattern 4. Card: TWX (twx-core-01 = registry + schema + NDC/PDC reference adapters).

## Twin Core
| Tool | File | Description | Input | Output |
|------|------|-------------|-------|--------|
| Twin Canonical Schema | tools/twin_core/schema.py | Canonical verdict (`pass\|warn\|fail`, + `unknown` sentinel), severity (`blocker\|critical\|high\|medium\|low`), category (`service_parity\|iam\|network\|compliance\|cost\|security`) and `target_csp` enums. Normalizes the 3 verdict families (pass/warn/fail, green/amber/red, pass/fail gates) and severity families (bare `high`, STIG `CAT1-3`, cATO `high/moderate/low`) without loss. Never fabricates a verdict; unknown → `unknown`. | `normalize_verdict/severity/csp`, `canonical_violation(...)`, `worst_verdict`, `twin_verdict(...)` | canonical violation dicts / envelope |
| Twin Registry | tools/twin_core/registry.py | Data-driven registry of thin per-canvas `TwinAdapter`s. Adapters self-register via `@register_twin`; `TwinRegistry.discover()` imports every module in `adapters/` by filesystem scan (no hardcoded canvas list). Display names cross-checked against `args/component_registry.yaml`. Base adapter degrades gracefully (canvases lacking `list_snapshots` return `[]`). | `TwinRegistry.get(key)/discover()/describe_all()` | `TwinAdapter` instances |
| NDC Twin Adapter | tools/twin_core/adapters/ndc.py | Wraps `tools/network/twin.py`. `method='heuristic'`. Maps `compliance_findings` → `network` violations; reads `network_twin_snapshots` for the list surface NDC's native module lacks. | `simulate_delta(project_id, topology_delta)` | canonical envelope |
| PDC Twin Adapter | tools/twin_core/adapters/pdc.py | Wraps `tools/pipeline/twin.py`. `method='static-analysis'`. Antipatterns → `security`, compliance-rule failures → `compliance`. Passes PDC's sha256 snapshot dedup + retention (pdx-perf-01) straight through. `latest_status` surfaces the newest persisted `pdc_simulations` verdict. | `simulate_delta(pipeline_id, delta_graph)` | canonical envelope |
| BDC Twin Adapter | tools/twin_core/adapters/bdc.py | Wraps `tools/boundary_canvas/twin.py`. Normalizes rating bands (`green/amber/red/unknown` → `pass/warn/fail/unknown`); `unknown` never green-washed. Carries `cod_method` (`heuristic`/`llm_debate`) through as violation `method`. `compliance` category. | `simulate_delta(project_id, control_delta)` | canonical envelope |
| SDC Twin Adapter | tools/twin_core/adapters/sdc.py | Wraps `tools/security_canvas/twin.py`. Attack paths → `security` violations (severity from path). `method='heuristic'`. | `simulate_delta(design_id, delta_graph)` | canonical envelope |
| DDC Twin Adapter | tools/twin_core/adapters/ddc.py | Wraps `tools/data_canvas/twin.py`. Verdict from `simulate_delta`, lineage-grounded violations from `quality_gate` → `compliance`. `method='lineage-analysis'`. | `simulate_delta(design_id, schema_changes)` | canonical envelope |
| ODC Twin Adapter | tools/twin_core/adapters/odc.py | Wraps `tools/observability_canvas/twin.py`. Coverage gaps → `security` violations; preserves `estimate`/`basis` provenance. `method='heuristic-estimate'`. | `simulate_delta(design_id, collector_delta)` | canonical envelope |
| IDC Twin Adapter | tools/twin_core/adapters/idc.py | Wraps the flat-file IDC IaC twin (`snapshot_writer.py` + `preapply_gate.py` — NOT a `twin/` package; see `idc-twin.md`). `simulate_delta` runs the pre-apply gate over Terraform `plan_json`, normalizing STIG `CAT1-3` → canonical severity. `take_snapshot` requires `graph=` (honest error otherwise). `method='iqe-gate'`. | `simulate_delta(project_id, plan_json)` | canonical envelope |
| Mission Twin Adapter | tools/twin_core/adapters/mission.py | Wraps `tools/mission_canvas/twin.py` (aggregator over DDC+PDC sub-twins). No native snapshot table. `method='aggregate'`. | `simulate_delta(mission_id, schema_changes)` | canonical envelope |
| Twin Event Bridge | tools/twin_core/event_bridge.py | Wires twin_core into the cross-canvas event bus (`tools/canvas/event_bus.py`). Registry facades `simulate()`/`snapshot()` auto-publish `twin_simulation_completed`/`twin_snapshot_taken` with the canonical verdict payload (no change to the 8 twins). Two cross-canvas subscriptions: PDC `pipeline_deployed`→SDC attack-path refresh; SDC `sdc_threat_model_changed`→BDC crosswalk-drift re-run. Honors the bus's classification-aware security-context propagation. `recent_twin_events()` feeds the Observatory (twx-obs-01); `create_twin_drift_card()` writes a **quarantined** (`status='suggested'`) kanban card only, gated off by default (`ICDEV_TWIN_DRIFT_CARDS`). Registered at startup from `security_canvas/blueprint.py`. | `register_subscriptions()`, `simulate/snapshot(canvas, id, ...)`, `recent_twin_events(limit)` | event ids / envelopes / feed |
| Twin Observer | tools/twin_core/observer.py | Cross-canvas twin health: snapshot freshness/age, verdict distribution (window, from canvases that persist sims), violation counts by severity (from canvases that persist violations), and refresh-schedule adherence joined against `genesis_reflex_state`. Best-effort — missing canvas DB/table degrades to `unavailable`/`None`. Library + CLI. Data source for the Twin Observatory (twx-obs-01). | `observe(window_hours=24)` / `python -m tools.twin_core.observer --json` | health report dict |

Event-bus wiring lands in **twx-bus-01**; the Twin Observatory dashboard in **twx-obs-01**. Mirrored to `icdev/tools/twin_core/`.

**Adapter honesty invariants preserved:** the canonical schema *wraps, never obscures*, each twin's `method` provenance — BDC heuristic-vs-llm_debate labeling and unknown-verdict honesty, PDC dedup/retention, ODC `estimate=True` basis, DDC lineage-grounding, IDC STIG-CAT scale. No verdict is ever fabricated.
