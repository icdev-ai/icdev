| CodeLens | tools/code_intelligence/codelens.py | Phase D exit validation gate (Phase 52 / D331-D337). | Dead-Code Lens | tools/code_intelligence/dead_code.py | CL-1+CL-2 (Fallow-inspired, deterministic, stdlib-only, air-gap safe). Detects dead functions/classes, orphan files, unused requirements deps (CL-1) + builds intra-repo import graph and finds circular dependencies via Tarjan SCC (CL-2). Every finding carries confidence + explanation + suggested action | --scan, --project-dir, --check {all,dead-code,orphans,deps,circular}, --explain, --graph, --json, --human, --gate | Report JSON {tool, target, summary{graph,by_kind}, findings[], graph?} |
| Deletion Evidence | tools/code_intelligence/deletion_evidence.py | CL-4 (Fallow Runtime analog, air-gap safe — uses data ICDEV already persists). Correlates dead_code findings with real runtime traffic from usage_events (per-route Flask hits) by parsing each file's @bp.route patterns and matching concrete hits within a window. Verdicts: orphan+hot→keep (false positive rescued), orphan+cold→delete (high), dead-symbol+hot→review (caution, never auto-delete). Degrades to no_signal when DB unavailable | --project-dir, --window-days, --check, --explain, --json, --human | Report JSON {tool, window_days, summary{by_runtime_signal,by_recommendation,confirmed_deletions,runtime_false_positives}, findings[+runtime,+verdict]} |
| Static Diff Lens | tools/analysis/static_diff_lens.py | ARC WS2.2 — bounded CodeLens run over CHANGED FUNCTIONS only. Parses `git diff <base>..<head>`, maps changed lines to enclosing function spans via AST, runs CodeAnalyzer + 3 diff-aware detectors (none-deref, off-by-one, missing-return) on those spans, and emits a `static_findings` EvidenceBundle key for `tools.workflow.self_debug.snapshot()` to feed into the diagnose prompt. Bounded by --max-files/--max-findings so it stays cheap. No LLM. | --task-id, --base, --head, --cwd, --max-files, --max-findings, --json | StaticDiffResult {task_id, base, head, files_in_diff, files_analyzed[], findings[], summary, truncated, notes} |
