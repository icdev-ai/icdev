Evidence / Evidence collectors

Evidence collectors for customer environments

Read-only collectors read a customer system's own sources: cloud configuration (AWS Config), the identity provider (OpenID Connect discovery and SCIM 2.0), endpoints (Microsoft Intune through Microsoft Graph) and the SIEM (Splunk). Credentials are taken only by reference from the customer's vault or the OS keyring, and never shown, logged or exported. Every observation carries when it was observed, by which collector, for which system, and a freshness budget: a stale observation counts for nothing, and an objective is never satisfied by absence. A reviewed mapping ({{ view.config.path }}, sha256 {{ (view.config.sha256 or '')[:12] }}) turns observations into SP 800-171 Rev. 2 and SP 800-53 Rev. 5 objective results; an objective that cannot be judged stays unverified. One {{ schema }} report per system per run (ICDEV[OS] contract {{ contract }}) is prepared by anyone and published to ICDEV[OS] by another person of the system's organisation ({{ template }}). This is evidence, not an assessment.
