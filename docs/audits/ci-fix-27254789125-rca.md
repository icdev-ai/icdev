## Root Cause
The Network Design Canvas `db/init_db.py` used ICDEV's shared `get_connection()`, which injects row-level security (RLS) predicates (`tenant_id`, `classification`) on every query. Network canvas tables do not have these columns, so the injected predicate raised `UndefinedColumn` on PostgreSQL, producing a server-side 500 on every route hit.

Additionally, some routes used SQLite-native JSON functions (`json_extract`, `json_each`) that do not exist in PostgreSQL, causing further 500s under `ICDEV_STORAGE_BACKEND=postgresql`.

## Fix
Already committed on task branch `kanban/ci-fix-27254789125`:

- `37a8ef32d` (`fix(network): disable RLS on canvas PG connections to prevent UndefinedColumn 500s`) — calls `conn.set_security_context(None)` in network `get_connection()` so RLS predicates are skipped for canvas tables that lack `tenant_id`/`classification` columns.
- `f87f9b4d7` (`fix(network): replace SQLite JSON functions with Python-side parsing for PG primary`) — moves JSON parsing from SQL to Python, making queries backend-agnostic.
