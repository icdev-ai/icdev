## Root Cause
The Network Design Canvas used SQLite-native JSON functions (`json_extract`, `json_each`) in its database queries. When `ICDEV_STORAGE_BACKEND=postgresql` (the production/CI default since PGP remediation), these functions do not exist in PostgreSQL, causing every route that executes them to raise a server-side 500.

## Fix
Already committed in `f87f9b4d7` (`fix(network): replace SQLite JSON functions with Python-side parsing for PG primary`), which lands **after** the triggering commit `feat(arc-dec-02)` on `irad/feature`.

The fix moves JSON parsing from SQL to Python, making the canvas backend-agnostic and compatible with the PostgreSQL-primary configuration.
