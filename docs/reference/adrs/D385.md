**Correction — the Remote Command Gateway already existed; the "stub gateway" claim came from a stale `icdev/` mirror.** The source docs described the gateway as a stub to be built. FALSE: `tools/gateway/` ships `gateway_agent.py` (Flask, multi-channel), `security_chain.py` (8 gates), `event_envelope.py`, `response_filter.py`, `user_binder.py`, and seven webhook adapters. `tools/gateway/` is **not mirrored to `icdev/`**, so a reader who inspected `icdev/tools/gateway/` (absent) wrongly concluded it did not exist. sag-gw-01 (agent-mode) and sag-gw-02 (Email adapter) EXTEND this real gateway; the security chain is unchanged.
