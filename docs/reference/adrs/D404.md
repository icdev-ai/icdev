**A memory system that captures nothing and a retrieval that always pays full cost are the same defect twice; both are fixed by WIRING, and `<private>` is dropped before the seam, not filtered after it.** `auto_capture.py` was complete and had **no hook caller** — `memory_buffer` held 0 rows on the live board while `memory_maintenance_reflex` and `heartbeat_daemon` dutifully flushed a buffer nothing filled — and `.claude/settings.json` wired every hook kind **except** `SessionStart`, so the Session Start Protocol this file documents was a manual step nobody ran. Three decisions. (1) **The injected context block is BOUNDED and the bound is reported**: capped at 1,500 tokens by `context_budget.estimate_tokens` and WITHHELD past a 1 s wall clock with `reason: over_budget`, measured live at 0.48–0.54 s and 425 tokens over 20 entries; `tokens` is None, never 0, when nothing was composed. A context hook that can hang is a liveness failure wearing a feature's name, so the budget refuses rather than delays. (2) **Capture is DETERMINISTIC and the kinds are closed** — `edit`, `commit`, `test_summary`, `decision` — with no model call anywhere, and `<private>...</private>` spans are stripped **before** `capture()` is reached (a test asserts a private span never lands in `memory_buffer`), because a filter downstream of the buffer has already written the thing it means to exclude. Measured over a 7-day transcript replay of the shipped predicate: **median 156 rows/day, 144 on the last full day**, mean 232.5 — *quote the median*, the mean is dragged by two multi-session build days, and the 7-to-563 spread is the operator's day and not the predicate's. Cost is +10 ms for a non-capturing event and +280 ms when an event yields an observation (16.6% of events), so the storage import is paid only by the minority that needs it. (3) **Progressive disclosure reuses the dashboard's chronology instead of authoring a second one**: the `audit_trail UNION ALL hook_events` query moved out of the Flask blueprint into `tools/dashboard/api/activity_query.py` and an AST test asserts that UNION is spelled as SQL in exactly one file. Two defects surfaced and were fixed on the way, both invisible without a replay: the pytest summary regex demanded the `===== N passed =====` bars while this repo runs `-q` (4 summaries became **1,140**, with the DURATION stripped so `24 passed in 1.13s` and `1.19s` stop being two facts), and on SQLite `audit_trail`/`hook_events` hold **both** timestamp spellings, so a `T`-form window bound silently excluded every space-form row of the same day. `hook_events.hook_type` now derives from ONE tuple, which found that `user_prompt_submit` and `pre_compact` had been written by two shipped hooks since they were authored and admitted by **no** constraint.
