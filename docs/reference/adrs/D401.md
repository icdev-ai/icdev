**An emulated estate is never readable as an observed one, and no emulator verdict may be a required check.** Four honesty rules govern every surface this phase added, and each is enforced rather than stated. (1) **Provenance `emulated`** — the `flx-twin-01` adapter reads the connector's seven logical tables THROUGH `tools/databridge/broker.py` as `twin_observatory_analyst` (the `flx-bridge-02` grant), so every read is authorized and audited; a direct connector import is the ungoverned side channel `cef-fnd-03` exists to close, and an AST test refuses one. `_persist_snapshot` takes **no** provenance parameter (asserted structurally, and CHECKed in the database by migration `20260905070028`), because a behavioural test over today's callers would still pass the day somebody threads a kwarg through. (2) **`unknown` is never `pass`, and an unanswerable question is not an empty answer** — a container-backed table on a socket-less host returns `unsupported_without_docker`, never `[]`, which is the `rmf-disc-02` defect exactly; `resource_count` is `None`, never 0, when nothing was measured. (3) **NEVER source a performance, cost or capacity claim from emulator timings** — `twx-spk-01`'s standing guard, carried forward UNCHANGED and now travelling ON the capability (the commands doc, the `flx-ci-01` report path, the `flx-twin-01` manifest row) rather than sitting in a spike nobody re-reads. The **IAM-sandbox NO-GO** carries forward on the same terms: the PDP/PEP ABAC engine already answers IAM questions offline and deterministically, and a partial emulation would give a second answer with no rule for choosing between them. (4) **The IaC gate is opt-in and NEVER one of the four required checks** (`workflow_dispatch` + weekly + a `floci-gate` label): runners here are near-serial, so an emulator in front of every merge is how a gate earns itself a bypass. Its four cells carry ONE finding — `gate_missed_rejection`; `gate_stricter_than_api` is what a compliance gate IS and can never be a finding — and either side unmeasured is `unmeasurable`, never agreement. The **Azure, GCP and OCI siblings are NOT built** (`flx-az-01`, `flx-gcp-01`, `flx-oci-01`, backlog): each is gated on its own **dated parity measurement**, exactly as this spike gated LocalStack, and none inherits floci's AWS parity by sharing its authors.
