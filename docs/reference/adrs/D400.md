**Air-gap capability is a MEASURED claim, not a licence claim.** Removing the auth token makes disconnected operation *possible*; it does not make it *true*, and three measurements say what it actually costs. (1) **Having `floci/floci:2.0.1` cached is NECESSARY AND NOT SUFFICIENT** — floci does not carry its container-backed runtimes inside its own image; Lambda, RDS, ElastiCache, OpenSearch, MSK and ECS/EC2/EKS each start a SEPARATE container from a base image resolved **from the public internet on first use**. Eleven such images were recorded from `docker events` while a live floci was driven through every container-backed service (2026-09-05, Docker 28.5.1) into `args/floci_runtime_images.yaml` — MEASURED, never read off a README — and the set is a function of the declared **variant** (a `python3.11` Lambda and a `nodejs20.x` one pull different images), not of the service, which is what makes a bare per-service list wrong. (2) **A pin is a DIGEST, never a tag** (`flx-airgap-01`): `tools/airgap/image_vendor.py` saves from the LOCAL cache and never pulls (structurally — an allowlisted `version|image|save|load` frozenset, AST-asserted), and verifies a bundle by re-hashing every OCI blob against its filename and matching `index.json` to the pin, with **no daemon required**, because media is verified before there is anywhere to load it. `unmeasured` exits 2 and is never a clean bundle. (3) A registry-mandating site cannot pre-seed hosts, so `flx-airgap-03` extends the ONE `airgap-emulator-runtime-images` rule with a second way to answer no — the pull is redirected to an **internal** mirror, judged against `args/twin_airgap_rules.yaml`'s own allowlist rather than a private copy. **There is deliberately no second rule**: two rules could disagree about what a run-time pull is, leaving a reviewer with two verdicts and no way to choose. Separately, the **host Docker socket is ROOT-EQUIVALENCE ON THE HOST** and ships as an explicit security decision — Gap 65 in `docs/security/sandbox-coverage.md`, behind the opt-in `floci` profile, every port bound to `127.0.0.1`, no `env_file`, and a test asserting floci is the ONLY service granted it.
