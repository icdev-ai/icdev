Extend, don't redesign — every DMX capability (temporal validity, cross-reference cascade, link-rot, freshness notifications, NIST/CVE feeds, regen gate) reuses the existing docmod scanner, the append-only `docmod_findings` supersede chain, the `drift_bridge` → ACOIC compliance sink, and the shared `tools.quality` grounding modules. No parallel finding store, no new compliance path, no new LLM verdict surface — preserves the 5 DOCMOD invariants (deterministic TRUST verdicts, append-only findings, HITL `pending_review` gating, air-gap safety, RLS tenant_id/classification).
