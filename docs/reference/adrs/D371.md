Cited-URL link-rot checking treats document URLs as an SSRF surface — the egress guard resolves each hostname to its IP(s) and checks EVERY resolved address (post-resolution, defeating DNS-rebinding) against loopback/RFC1918/link-local (incl. cloud instance-metadata)/multicast/reserved before any socket opens; https-only, denylist-wins allow/deny, no auto-followed redirects, per-sweep cap. Air-gap-unreachable is never scored as "rotted". (Sandbox-coverage Gap 32.)
