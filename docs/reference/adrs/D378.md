**New snapshot tables follow the PDC retention pattern, NOT append-only.** `qdc_twin_snapshots`, `aadc_twin_snapshots`, `aiml_twin_snapshots` use sha256 dedup + bounded auto-snapshot retention (like `pdc_snapshots`) and are deliberately ABSENT from `APPEND_ONLY_TABLES` (they are prunable log-rotation surfaces). Created via each canvas's own `db/init_db.py` (the registry-declared migration path — PG-canvas-DB correct, avoids the migration-number hotspot) + conftest entries. Canvas connection helpers (`get_canvas_connection()`-backed) are used because canvas tables lack `tenant_id`/`classification` RLS columns. No new append-only audit tables were introduced by TWX.
