# SDC Demo Playbook — Leadership Edition (15 minutes)
**Audience**: DoD/IC Senior Leadership, CISOs, Program Managers
**Goal**: Show Red Team → SDC Automation → Compliant in 15 minutes
**Tagline**: "200 hours manual to 4 hours automated. $29,400 saved per engagement."

---

## Pre-Demo Checklist (5 minutes before)

```bash
# Verify demo data
python tools/db/seeds/seed_sdc_demo.py --verify --json

# Confirm dashboard running
python -c "import urllib.request; urllib.request.urlopen('http://localhost:5050/health', timeout=3); print('OK')"

# Navigate to SDC Demo Runner
# http://localhost:5050/security/demo
```

**Browser tabs to open**:
1. `http://localhost:5050/security/demo` — SDC Demo Runner (primary)
2. `http://localhost:5050/security/` — Security Canvas (backup)

**Audience selector**: Set to **Executive** before leadership enters.

---

## Act 1 — Red Team: Before State (5 minutes)

**Click**: Scenario A (Red Team button, red border)

**Talking points as results render**:

> "This is the live system — no slides. What you're seeing is an actual security assessment of our IL5 web application platform."

**Key numbers to call out**:
- **15 CAT1 findings** — "These are the DISA STIG Category I findings. Each one is a potential cATO blocker."
- **3 live attack paths** — "An adversary today has three confirmed paths to your sensitive data. Path 1 goes through an unpatched SQLi vulnerability — CVE-confirmed."
- **Risk score 8.7 / 10** — "NIST 800-53 risk threshold for IL5 is 7.0. We're at 8.7."
- **Posture grade F** — "ISSO would not approve this system today."
- **200 hours** — "Manual remediation estimate: 200 person-hours at $150/hr. That's $30,000 and 5 weeks."

**IQE Query to type live**:
```
foreach t in sdc_demo.threat_summary where t.snapshot_label == "before" where t.cat1_count > 0 select t.design_id, t.cat1_count, t.risk_score, t.posture_grade
```

**Hook question**: *"If you had a major audit tomorrow, how many of your systems would show a report like this?"*

---

## Act 2 — SDC 12-Step Workflow (5 minutes)

**Click**: Scenario B (Workflow button, blue border) + enable **Simulate ISSO** checkbox

**Talking points**:

> "Now I'm going to run the Security Design Canvas automated workflow. Watch the 12 steps execute — threat scan, STIG check, risk scoring, ISSO approval, IaC generation, Terraform apply."

**Steps to narrate**:
1. **Steps 1–3** (Threat Scan → STIG Check → Risk Scoring): "Automated — took 4 minutes. Manually this is 2–3 days."
2. **Step 4 — ISSO Approval Gate**: "This is the human-in-the-loop gate. In simulate mode, our ISSO is approving it now — in production, the ISSO gets a notification, reviews the assessment package, and clicks approve. We're seeing: `isso-demo@agency.gov` approved."
3. **Steps 5–9** (IaC Gen → Policy → Terraform → Ansible): "Fully automated. The system is now remediating the findings in real time."
4. **Steps 10–12** (Post-Deploy Scan → Crosswalk → Evidence): "Verification complete. Evidence package assembled."

**Metric to highlight**: "12 steps. 17 hours wall clock. 4 automated hours. Compare to 5 weeks manual."

---

## Act 3 — After State: Compliant (5 minutes)

**Click**: Scenario C (Compliant button, green border)

**Talking points**:

> "Here's the same system after SDC ran. Same day."

**Key numbers**:
- **0 CAT1 findings** — "Every Category I finding is resolved. ISSO can now sign."
- **Posture grade A** — "The system went from F to A in 17 hours."
- **$29,400 saved** — "196 hours × $150/hr. That's per engagement."
- **87% NIST 800-53 coverage** — "Automatically crosswalked to FedRAMP Moderate (82%) and CMMC L2 (91%)."
- **cATO Ready** — "This design can now enter continuous ATO monitoring."

**IQE Query to type live**:
```
foreach t in sdc_demo.threat_summary where t.snapshot_label == "after" where t.cat1_count == 0 select t.design_id, t.posture_grade, t.controls_implemented, t.risk_score
```

**Terraform IaC**: Expand the IaC snippet section. *"This Terraform was generated by the system — production-ready, NIST-compliant, ready for pipeline deployment."*

**Close**: *"From 47 findings and 3 attack paths to 0 CAT1 and posture A — automated, auditable, repeatable."*
