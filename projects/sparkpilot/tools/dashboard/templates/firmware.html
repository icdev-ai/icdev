What is Firmware?

Firmware is the software that runs on your embedded device (like an ESP32 or STM32). SparkPilot compiles your code into a firmware binary, then sends it to your device wirelessly via OTA (Over-The-Air) updates. Think of it like updating an app on your phone — but for hardware!

1
Write code (Missions)
2
Builder compiles it
3
OTA sends to device
4
Device runs new code

Firmware Builds

The Embedded Builder Agent compiles your FreeRTOS C code into a binary file. Each build targets a specific board (ESP32, STM32, etc.) and includes the SparkPilot SDK (~8KB).
